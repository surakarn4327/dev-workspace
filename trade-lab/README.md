# trade-lab

ห้องแล็บวิจัยตลาด รันบนเครื่องตัวเอง — ตอบคำถามว่า **แนวคิดเทคนิคไหนทำกำไรได้จริง
แนวคิดไหนแค่ความเชื่อ** ด้วยตัวเลขจากข้อมูลราคาจริง ไม่ใช่ความรู้สึก

## มันทำอะไร

ไล่ดูราคาย้อนหลังเป็นแสนแท่ง หาทุกจุดที่ราคา **กลับตัว / เด้ง / เริ่มวิ่งจริง**
แล้วตรวจว่าจุดเหล่านั้นมีอะไรอยู่บ้าง — FVG, demand/supply zone, order block,
liquidity sweep, CRT, trendline, แนวรับแนวต้าน, session รวมถึง indicator พื้นฐาน
อย่าง RSI / MACD / EMA / ADX / Bollinger — แล้วเทียบกับจุดที่ราคาผ่านไปเฉยๆ
เพื่อดูว่าอันไหนมีนัยจริง

ผลที่ได้หน้าตาประมาณนี้:

| เงื่อนไข | ประเภท | Expectancy | n | Holdout |
|---|---|---|---|---|
| FVG ค้าง + ยังไม่ fill | กลับตัว | +0.36R | 1,847 | ผ่าน |
| RSI < 30 เดี่ยวๆ | เด้ง | −0.31R | 4,102 | ไม่ผ่าน |
| บีบตัว 20 แท่ง + ทะลุ London | ก่อนวิ่ง | +0.74R | 341 | ผ่าน |

*(ตัวอย่างสมมติ — ของจริงต้องรัน และมีโอกาสที่เกือบทุกอันจะไม่ผ่าน ซึ่งก็เป็นคำตอบที่มีค่า)*

จากนั้นเอาเงื่อนไขที่ผ่านไปทำ **indicator บน TradingView** หรือ **EA** ต่อได้

## มันไม่ได้ทำอะไร

- ไม่ทำนายว่าพรุ่งนี้ราคาจะขึ้นหรือลง
- ไม่รับประกันกำไร — เงื่อนไขที่แม่น 40% ก็ยังผิด 60%
- ไม่ยิงคำสั่งเทรด (ถ้าจะเทรดจริง ไปที่ [`smart-ea`](../smart-ea))
- ไม่ดูข่าว — เทคนิคอย่างเดียว
