## 2026-09-07 — ร่างแรกใช้ไวยากรณ์ที่ Pine ไม่รองรับ

**อาการ** — ร่างแรกของ `ma-ribbon-signal.pine` เขียนแล้วคอมไพล์ไม่ผ่าน (จับได้จากการรีวิว
ก่อน paste ลง Pine Editor)

**สาเหตุ** — เขียนด้วยความเคยชินจากภาษาอื่น 3 จุดที่ Pine ห้าม:
1. ประกาศฟังก์ชัน `cell()` ไว้ข้างใน `if showDash and barstate.islast` — Pine อนุญาตให้
   ประกาศฟังก์ชันที่ระดับ global เท่านั้น
2. assign หลายตัวบรรทัดเดียวคั่น comma — `sma1 = ma(s1), sma2 = ma(s2)` และ
   `var line lnE = na, var line lnS = na` — Pine ไม่มีไวยากรณ์นี้เลย
3. เรียกหลายคำสั่งคั่น comma ในบอดี้ฟังก์ชัน — `line.delete(lnE), line.delete(lnS)`
4. ตั้ง default value ให้พารามิเตอร์ฟังก์ชัน (`color col = na`) — Pine ไม่รองรับ default arg

**วิธีแก้** — เขียนใหม่ทั้งไฟล์: ย้ายทุกฟังก์ชันขึ้น global, แยก assign เป็นบรรทัดละตัว,
แทน `cell()` helper ด้วยการเรียก `table.cell()` ตรงๆ ทุกช่อง (ยาวกว่าแต่ถูกไวยากรณ์)
กฎทั้ง 4 ข้อนี้เขียนกำกับไว้ใน `CLAUDE.md` แล้ว
