# ma-ribbon

TradingView Pine Script indicator ที่พอร์ตมาจาก `MA_Ribbon_Signal_Indicator.ex5` (MT5)
พร้อม **dashboard สถิติ** ที่บอกว่า SL / TP1 / TP2 / TP3 โดนกันคนละกี่เปอร์เซ็นต์
จากประวัติที่โหลดอยู่บนชาร์ต

## วิธีใช้

1. เปิด TradingView → Pine Editor
2. copy เนื้อไฟล์ `ma-ribbon-signal.pine` ไปวาง
3. Save → Add to chart

ไม่มี build / dev server — เป็นสคริปต์ไฟล์เดียวที่รันบน TradingView

## indicator ทำอะไร

- **Ribbon** — EMA กลุ่มสั้น (5, 8, 11, 14, 17, 20) เทียบกลุ่มยาว (30, 35, 40, 45, 50, 55, 60)
  ระบายสีระหว่าง EMA(5) กับ EMA(60): เขียว = ค่าเฉลี่ยกลุ่มสั้นอยู่เหนือกลุ่มยาว, แดง = อยู่ใต้
- **Signal** — ลูกศรตอนค่าเฉลี่ยกลุ่มสั้นตัดกลุ่มยาว
- **SL** — ATR(14) × 1.5 หรือ swing high/low 10 แท่ง (เลือกได้) + buffer 50 points
- **TP** — 2R / 3R / 4R จากระยะ SL
- **Dashboard** — สัญญาณปัจจุบัน + ตารางสถิติ hit rate ต่อ level + expectancy (หน่วย R)

## dashboard อ่านยังไง

| แถว | ความหมาย |
|---|---|
| `SL` | จำนวน/สัดส่วนเทรดที่ราคาไปแตะ SL |
| `TP1` / `TP2` / `TP3` | เทรดที่ไปถึง level นั้น **ก่อน** แตะ SL (นับซ้อนกัน — ถึง TP3 ก็นับ TP1 TP2 ด้วย) |
| `Flat exit` | ปิดเพราะเกิดสัญญาณสวนทาง โดยยังไม่แตะทั้ง SL และ TP1 |
| `Trades closed` | ตัวหารของทุกเปอร์เซ็นต์ข้างบน (เทรดที่ปิดแล้วเท่านั้น) |
| `Expectancy / trade` | กำไรคาดหวังต่อเทรดหน่วย R: ออกที่ level สูงสุดที่ไปถึง, −1R ถ้าโดน SL, 0R ถ้า flat |

## ข้อจำกัดที่ต้องรู้

- **สถิติเป็นค่าต่ำสุด (floor) ไม่ใช่ค่าจริงเป๊ะ** — ถ้าแท่งเดียวแตะทั้ง SL และ TP
  สคริปต์นับว่า SL โดนก่อน เพราะจาก OHLC บอกลำดับในแท่งไม่ได้
- **ไม่มี spread / commission / slippage** ในการคำนวณ ตัวเลขจริงจะแย่กว่านี้
- ถือได้ทีละ 1 เทรด สัญญาณใหม่ปิดเทรดเก่าทันที (เหมือนต้นฉบับ MT5)
- จำนวนเทรดขึ้นกับประวัติที่ TradingView โหลดให้ (แผนฟรีจำกัดจำนวนแท่ง)
  → เทียบสถิติข้าม timeframe ต้องระวังว่าจำนวนเทรดไม่เท่ากัน
- `SL Buffer (in points)` ใช้ `syminfo.mintick` เป็นหน่วย ซึ่งอาจไม่เท่ากับ "point" ของ MT5
  ถ้าอยากได้ผลตรงกับ MT5 เป๊ะ ต้องเช็ค digits ของ broker แล้วปรับค่านี้
