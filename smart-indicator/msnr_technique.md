## แกนกลาง (ทุก preset)

- คำนวณจากแท่งที่ **ปิดแล้ว** ของ "ไทม์เฟรมคำนวณเส้น" เท่านั้น (`request.security` + `[1]` + `lookahead_on` = ไม่ repaint)
  ตั้งเล็กกว่าชาร์ต = ใช้ TF ชาร์ตแทน
- ใช้ตัวเทียน (open/close) วาดเส้น ไม่ใช้ไส้
- **ทะลุ = ตัวเทียนปิดผ่าน** (แนวต้าน: close > top, แนวรับ: close < bot) ไส้ทะลุไม่นับ
- ทะลุแล้วกลับหน้าที่: แนวรับ → **SBR**, แนวต้าน → **RBS** กลับเป็น fresh, ล้าง touch/ห้ามเทรด/signaled
- **แตะ** = ไส้ถึงเส้น (แนวต้าน: high ≥ bot, แนวรับ: low ≤ top) / **ตัวเทียนแตะ** = max/min(open,close) ถึงเส้น
- fresh = เส้นทึบ, ใช้แล้ว = เส้นประ, SBR/RBS หนากว่า 1 ขั้น, ห้ามเทรด = สีเทา + ✘
- doji (open = close) ไม่นับเป็นแท่งเขียวหรือแดง

## นิยามเส้น

| ชนิด | เงื่อนไข | ราคา | เริ่มเช็คแตะ/ทะลุ |
|---|---|---|---|
| A/V ยอด/ก้นราคาปิด | close[p] สูงกว่า (A) / ต่ำกว่า (V) close ซ้าย `pivotLen` แท่ง (เข้ม) และขวา `pivotLen` แท่ง (เท่ากันได้) | close[p] | แท่ง p+2 (replay ย้อนตอนยืนยัน) |
| A/V คู่แท่ง | A = เขียว→แดง, V = แดง→เขียว | close แท่งแรก | แท่งถัดจากคู่ |
| A/V แถบปิด-เปิด | เหมือนยอด/ก้น | แถบ close[p] ↔ open[p+1] | แท่ง p+2 |
| Gap | 2 แท่งสีเดียวกัน (เขียว = แนวรับ, แดง = แนวต้าน) + ช่องว่างจริง (ถ้าเปิด): เขียว open2 > close1, แดง open2 < close1 | close1 / open2 / กึ่งกลาง / แถบ | แท่งถัดจากคู่ |

แท่ง p+1 (แท่งกลับตัว) และแท่งที่ประกอบคู่ ไม่ถูกนับเป็นการแตะ เพราะเป็นตัวสร้างเส้นเอง

## กฎแตะครั้งแรกด้วยตัวเทียน

เส้น fresh ที่ยังไม่เคยถูกแตะ ถ้าการแตะครั้งแรกเป็นตัวเทียน (ไม่ใช่แค่ไส้) → `noTrade` (สีเทา + ✘) ไม่ขึ้นแท่งยืนยัน
จนกว่าจะถูกปิดทะลุแล้วกลับหน้าที่ — กฎนี้มีผลจริงกับเส้นแบบแถบเป็นหลัก (เส้นเดียว ตัวเทียนแตะโดยไม่ปิดทะลุเกิดได้แค่ตอน
เปิด gap ข้าม หรือปิดเท่าเส้นพอดี) แหล่ง: โน้ต Studocu ฉบับเดียว (ผู้ใช้ตัดสินใจใส่ 2026-10-17)

ฝั่งแท่งยืนยันเช็คกฎนี้กับแท่งชาร์ตทันทีด้วย (ไม่รอแท่ง TF คำนวณปิด) กันไม่ให้แท่งที่ตัวเทียนแตะครั้งแรกขึ้นสัญญาณ

## แท่งยืนยัน (TF ชาร์ต, แท่งปิดแล้วเท่านั้น)

เงื่อนไขร่วม: แท่งแตะเส้นโดยไม่ปิดทะลุ (แนวรับ: low ≤ top และ close ≥ bot, แนวต้านกลับกัน), เส้น fresh (ปิดได้),
ไม่ใช่ห้ามเทรด, เส้นนั้นยังไม่เคยขึ้นสัญญาณ (1 เส้น 1 ครั้ง จนกว่าจะกลับหน้าที่) — แนวรับ = ลูกศรซื้อใต้แท่ง, แนวต้าน = ลูกศรขายเหนือแท่ง

| ชื่อ | นิยาม |
|---|---|
| ENG Engulfing | สีตรงข้ามแท่งก่อน ตัวเทียนครอบตัวเทียนแท่งก่อนทั้งหมด |
| PIN Pinbar | ไส้ฝั่งเส้น ≥ 2/3 ของแท่ง + ตัวเทียนทั้งตัวอยู่ฝั่งเดิมของเส้น (แนวรับ: min(o,c) > top) |
| HAM Hammer | ไส้ล่าง ≥ `wickRatio` × ตัวเทียน และ ≥ 50% ของแท่ง, ไส้บน ≤ 25% (ที่แนวต้าน = Hanging man) |
| IHAM Inverted Hammer | กลับด้าน HAM (ที่แนวต้าน = Shooting star) |

ลำดับความสำคัญถ้าเข้าหลายแบบ: ซื้อ ENG > PIN > HAM > IHAM, ขาย ENG > PIN > IHAM > HAM — แสดงแบบเดียว
แสดงผลด้วย `plotshape` (ไม่กินโควตา label) + `alertcondition` 2 ตัว (ซื้อ/ขาย)

## หน้าตั้งค่า (ลำดับกลุ่ม)

เปิด/ปิด (MSNR, แท่งยืนยัน) → ตั้งค่า MSNR → ตั้งค่า MSNR — แบบตั้งเอง → ตั้งค่าแท่งยืนยัน
สีเริ่มต้น: แนวต้าน `color.red`, แนวรับ `color.green`, ห้ามเทรด `color.gray`, ซื้อ `color.teal`, ขาย `color.orange`
แถบใช้สีเดียวกับเส้น พื้นหลังโปร่งใส 90

## การแสดงผล

- วาดทุกอย่างด้วย `xloc.bar_time` + `extend.right` (ไม่ใช้ `bar_index` — เลี่ยงบั๊กเพดาน `max_bars_back` ใน `bugs.md`)
- สไตล์/การซ่อนเส้นทำครั้งเดียวที่ `barstate.islast` (drawing แสดงแค่สถานะสุดท้ายอยู่แล้ว)
- "จำนวนเส้นเหนือ/ใต้ราคา" ซ่อนเส้นที่ไกลกว่า N เส้นแรกแต่ละฝั่ง (ทำเป็นโปร่งใส ไม่ได้ลบ) — เส้นแถบที่ราคาอยู่ข้างในแสดงเสมอ
- เก็บเส้นสูงสุด `maxKeep` (default 150) เกินแล้วลบเก่าสุด
- label ชื่อเส้น: แนวต้านใช้ `style_label_down` (ข้อความเหนือเส้น), แนวรับใช้ `style_label_up` (ใต้เส้น) — ชื่อ style กลับด้าน ดู `bugs.md`
