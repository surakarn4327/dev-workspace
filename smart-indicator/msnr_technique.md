## แกนกลาง (ทุก preset)

- คำนวณจากแท่งที่ **ปิดแล้ว** ของ "ไทม์เฟรมคำนวณเส้น" เท่านั้น (`request.security` + `[1]` + `lookahead_on` = ไม่ repaint)
  ตั้งเล็กกว่าชาร์ต = ใช้ TF ชาร์ตแทน
- ใช้ตัวเทียน (open/close) วาดเส้น ไม่ใช้ไส้
- **ทะลุ = ตัวเทียนปิดผ่าน** (แนวต้าน: close > top, แนวรับ: close < bot) ไส้ทะลุไม่นับ
- ทะลุแล้วกลับหน้าที่: แนวรับ → **SBR**, แนวต้าน → **RBS** กลับเป็น fresh, ล้าง touch/ห้ามเทรด/signaled
- **แตะ** = ไส้ถึงเส้น (แนวต้าน: high ≥ bot, แนวรับ: low ≤ top) / **ตัวเทียนแตะ** = max/min(open,close) ถึงเส้น
- fresh = เส้นทึบ, ใช้แล้ว = เส้นประ, SBR/RBS หนากว่า 1 ขั้น, ห้ามเทรด = สีเทา + ✘
- doji (open = close) ไม่นับเป็นแท่งเขียวหรือแดง

## นิยามเส้น

| ชนิด | เงื่อนไข | ราคา | เริ่มเช็คแตะ/ทะลุ |
|---|---|---|---|
| A/V ยอด/ก้นราคาปิด | close[p] สูงกว่า (A) / ต่ำกว่า (V) close ซ้าย `pivotLen` แท่ง (เข้ม) และขวา `pivotLen` แท่ง (เท่ากันได้) | close[p] | แท่ง p+2 (replay ย้อนตอนยืนยัน) |
| A/V คู่แท่ง | A = เขียว→แดง, V = แดง→เขียว | close แท่งแรก | แท่งถัดจากคู่ |
| A/V แถบปิด-เปิด | เหมือนยอด/ก้น | แถบ close[p] ↔ open[p+1] | แท่ง p+2 |
| Gap | 2 แท่งสีเดียวกัน (เขียว = แนวรับ, แดง = แนวต้าน) + ช่องว่างจริง (ถ้าเปิด): เขียว open2 > close1, แดง open2 < close1 | close1 / open2 / กึ่งกลาง / แถบ | แท่งถัดจากคู่ |

แท่ง p+1 (แท่งกลับตัว) และแท่งที่ประกอบคู่ ไม่ถูกนับเป็นการแตะ เพราะเป็นตัวสร้างเส้นเอง

## Preset

|---|---|---|---|---|---|
| มาตรฐาน (default) | ยอด/ก้น | ช่องว่างจริง, close1 | ไส้แตะ | เก็บเส้นประ | ปิด |
| Alchemist | คู่แท่ง | ไม่ต้องมีช่องว่าง, close1 | ไส้แตะ | เก็บเส้นประ | ปิด |
| แถบ | แถบปิด-เปิด | ช่องว่างจริง, แถบ | ไส้แตะ | เก็บเส้นประ | เปิด |
| เข้มงวด | ยอด/ก้น | ช่องว่างจริง, close1 | ไส้แตะ | ลบทิ้ง | เปิด |
| ตั้งเอง | ค่าจากกลุ่ม "แบบตั้งเอง" ทุกข้อ | | | | |

"แถบ" กับ "เข้มงวด" ไม่ใช่สำนักจริง — รวมกฎที่เข้ากันได้จากหลายแหล่ง (ดู `msnr_research.md`)

## กฎแตะครั้งแรกด้วยตัวเทียน

เส้น fresh ที่ยังไม่เคยถูกแตะ ถ้าการแตะครั้งแรกเป็นตัวเทียน (ไม่ใช่แค่ไส้) → `noTrade` (สีเทา + ✘) ไม่ขึ้นแท่งยืนยัน
จนกว่าจะถูกปิดทะลุแล้วกลับหน้าที่ — กฎนี้มีผลจริงกับเส้นแบบแถบเป็นหลัก (เส้นเดียว ตัวเทียนแตะโดยไม่ปิดทะลุเกิดได้แค่ตอน
เปิด gap ข้าม หรือปิดเท่าเส้นพอดี) แหล่ง: โน้ต Studocu ฉบับเดียว (ผู้ใช้ตัดสินใจใส่ 2026-10-17)

ฝั่งแท่งยืนยันเช็คกฎนี้กับแท่งชาร์ตทันทีด้วย (ไม่รอแท่ง TF คำนวณปิด) กันไม่ให้แท่งที่ตัวเทียนแตะครั้งแรกขึ้นสัญญาณ

## แท่งยืนยัน (TF ชาร์ต, แท่งปิดแล้วเท่านั้น)

เงื่อนไขร่วม: แท่งแตะเส้นโดยไม่ปิดทะลุ (แนวรับ: low ≤ top และ close ≥ bot, แนวต้านกลับกัน), เส้น fresh (ปิดได้),
ไม่ใช่ห้ามเทรด, เส้นนั้นยังไม่เคยขึ้นสัญญาณ (1 เส้น 1 ครั้ง จนกว่าจะกลับหน้าที่) — แนวรับ = ลูกศรซื้อใต้แท่ง, แนวต้าน = ลูกศรขายเหนือแท่ง

| ชื่อ | นิยาม |
|---|---|
| ENG Engulfing | สีตรงข้ามแท่งก่อน ตัวเทียนครอบตัวเทียนแท่งก่อนทั้งหมด |
| PIN Pinbar | ไส้ฝั่งเส้น ≥ 2/3 ของแท่ง + ตัวเทียนทั้งตัวอยู่ฝั่งเดิมของเส้น (แนวรับ: min(o,c) > top) |
| HAM Hammer | ไส้ล่าง ≥ `wickRatio` × ตัวเทียน และ ≥ 50% ของแท่ง, ไส้บน ≤ 25% (ที่แนวต้าน = Hanging man) |
| IHAM Inverted Hammer | กลับด้าน HAM (ที่แนวต้าน = Shooting star) |

ลำดับความสำคัญถ้าเข้าหลายแบบ: ซื้อ ENG > PIN > HAM > IHAM, ขาย ENG > PIN > IHAM > HAM — แสดงแบบเดียว
แสดงผลด้วย `plotshape` (ไม่กินโควตา label) + `alertcondition` 2 ตัว (ซื้อ/ขาย)

## หน้าตั้งค่า (ลำดับกลุ่ม)

เปิด/ปิด (MSNR, แท่งยืนยัน, Storyline, จุดเข้า) → ตั้งค่า MSNR → ตั้งค่า MSNR — แบบตั้งเอง → ตั้งค่าแท่งยืนยัน → ตั้งค่า Storyline
→ ตั้งค่าจุดเข้า/SL/TP → ตั้งค่า Trendline → ตั้งค่า Liquidity
สีเริ่มต้น: แนวต้าน `color.red`, แนวรับ `color.green`, ห้ามเทรด `color.gray`, ซื้อ `color.teal`, ขาย `color.orange`
แถบใช้สีเดียวกับเส้น พื้นหลังโปร่งใส 90

## การแสดงผล

- วาดทุกอย่างด้วย `xloc.bar_time` + `extend.right` (ไม่ใช้ `bar_index` — เลี่ยงบั๊กเพดาน `max_bars_back` ใน `bugs.md`)
- สไตล์/การซ่อนเส้นทำครั้งเดียวที่ `barstate.islast` (drawing แสดงแค่สถานะสุดท้ายอยู่แล้ว)
- "จำนวนเส้นเหนือ/ใต้ราคา" ซ่อนเส้นที่ไกลกว่า N เส้นแรกแต่ละฝั่ง (ทำเป็นโปร่งใส ไม่ได้ลบ) — เส้นแถบที่ราคาอยู่ข้างในแสดงเสมอ
- เก็บเส้นสูงสุด `maxKeep` (default 150) เกินแล้วลบเก่าสุด
- label ชื่อเส้น: แนวต้านใช้ `style_label_down` (ข้อความเหนือเส้น), แนวรับใช้ `style_label_up` (ใต้เส้น) — ชื่อ style กลับด้าน ดู `bugs.md`

## ลำดับในแต่ละแท่ง TF คำนวณ (กันบั๊กพลาด 1 แท่ง)

1. อัปเดตเส้นเก่าทั้งหมดด้วยแท่งที่เพิ่งปิด
2. สร้างเส้นใหม่ — เส้นจากคู่แท่งเริ่มเช็คแท่งถัดไป, เส้นยอด/ก้น (ยืนยันช้า `pivotLen` แท่ง) **replay** แท่ง p+2..ล่าสุด
   ทันทีตอนสร้าง (เหตุผลเดียวกับบั๊ก "loop อัปเดตของเก่ารันก่อนสร้างของใหม่" ใน `bugs.md`)

## Storyline (เฟส 2)

คำนวณจากแท่งปิดแล้วของ "ไทม์เฟรม storyline" (default `60` = 1 ชั่วโมง ผู้ใช้เลือก 2026-10-17 คู่กับเส้น `60` และเปิดกราฟ 5 นาที, ไม่ repaint แบบเดียวกับเส้น) ควรใหญ่กว่า "ไทม์เฟรมคำนวณเส้น"
1 ขั้น — ผู้ใช้เลือกวิธีได้ 2 แบบ (แหล่งข้อมูลขัดกัน ดู `msnr_research.md` ข้อ 8):

**1. แตะแล้วตีกลับ + ทะลุ (default, สาย Alchemist)**
1. เก็บเส้นยอด/ก้นราคาปิดของ TF storyline ไว้ภายใน (ไม่วาด, `stPivotLen`, ใช้ `step` ตัวเดียวกับเส้นหลัก — preset เข้มงวดจะลบเส้นที่ใช้แล้วด้วย)
2. แท่ง storyline แตะเส้น **fresh** แล้วปิดตีกลับฝั่งเดิม = rejection (แนวต้าน → รอขาลง, แนวรับ → รอขาขึ้น)
   ถ้าทิศเดียวกับ storyline ปัจจุบัน ไม่ทำอะไร
3. จุดยืนยัน (`pendBreak`) = เส้นหลัก (TF คำนวณเส้น) ฝั่งตรงข้ามที่ใกล้ราคาปิด storyline ที่สุด (รอขาลง = แนวรับใต้ราคา)
   ถ้าไม่มีเส้น ใช้ตัวเทียนของแท่ง rejection (รอขาลง = min(open,close))
4. แท่ง TF คำนวณเส้นปิดทะลุจุดยืนยัน = storyline เปลี่ยนทิศ
5. แท่ง storyline ปิดกลับทะลุเส้นที่ถูก rejection = ยกเลิกการรอ
6. storyline คงทิศเดิมจนกว่าทิศตรงข้ามจะยืนยัน (ไม่มีกลับไป "ยังไม่ชัด")

**2. ยอด/ก้น (BOS/CHoCH)** — ราคาปิด storyline ทะลุยอดล่าสุด (pivot ราคาปิด) = ขาขึ้น, ทะลุก้นล่าสุด = ขาลง
ยอด/ก้นที่ถูกทะลุแล้วไม่ใช้ซ้ำ รอ pivot ใหม่

**Roadblock:** เส้นหลักที่สวนทิศ storyline และอยู่ขวางทาง (ขาขึ้น = แนวต้านเหนือราคา, ขาลง = แนวรับใต้ราคา) — สี `color.purple`
ชื่อเส้นต่อท้าย "RB" (นับทั้ง fresh และใช้แล้ว)

**กรองแท่งยืนยัน (default เปิด):** ขาขึ้นขึ้นแค่ลูกศรซื้อ, ขาลงแค่ลูกศรขาย, ยังไม่ชัดขึ้นทั้งสองฝั่ง

**แสดงผล:** ป้าย ST▲/ST▼ (`plotshape`) ที่แท่งที่ทิศเปลี่ยน, ตารางมุมจอ (default ขวาบน) บอกทิศ + จุดที่รอปิดทะลุ,
`alertcondition` "storyline เปลี่ยนทิศ"

**ลำดับต่อแท่ง:** storyline engine → engine เส้นหลัก → เช็คปิดทะลุ `pendBreak` → แท่งยืนยัน → วาด/roadblock (แท่งสุดท้าย)

## เฟส 3

**Miss** (ช่อง "นับ Miss", default เปิด) — นับบนแท่งปิดของ TF คำนวณเส้น: แท่ง k-1 เป็นยอดย่อย (high สูงกว่าแท่งก่อนและ ≥ แท่งหลัง)
ที่อยู่ใต้แนวต้านไม่เกิน `missAtr` × ATR(14) ของ TF คำนวณเส้น (default 0.5) โดยไส้ไม่ถึงเส้น = miss 1 ครั้ง (แนวรับกลับกัน)
นับเฉพาะเส้น fresh ที่ยังไม่เคยถูกแตะ และเกิดก่อนแท่ง k-2 — ป้ายต่อท้าย `M2` ฯลฯ ทะลุแล้วกลับหน้าที่ = รีเซ็ตเป็น 0
แท่งยืนยันกรองได้ด้วย "ต้องมี Miss อย่างน้อย" (default 0 = ไม่กรอง) — ระยะ ATR เป็นการตีความของเราเอง แหล่งไม่ได้ระบุระยะ

**Decision level** (default เปิด, ต้องเปิด Storyline) — Gap ที่ช่วง high-low ของ 2 แท่งที่สร้าง gap ครอบราคาเส้นใดเส้นหนึ่งของ
TF storyline = decision (ป้าย `DL`) — **ไม่กลายเป็นเส้นใช้แล้ว** (Alchemist: ใช้ซ้ำได้ไม่เสื่อม) แต่ยังทะลุ/กลับหน้าที่ได้ตามปกติ
แหล่งเดิมพูดถึง H4 โดยเฉพาะ — ที่นี่ใช้ TF คำนวณเส้นอะไรก็ได้ — เส้นของ TF storyline ถูกเก็บในทั้ง 2 วิธีของ storyline แล้ว

**จุดเข้า/SL/TP** (master toggle "จุดเข้า", ต้องเปิดแท่งยืนยัน) — **แก้ 2026-10-17 ให้ตรงตำรา** (รอบแรกผมตั้งค่าเองหลายจุดโดยไม่ได้อิงแหล่ง — ดูตาราง "ที่มาของทุกกฎ" ด้านล่าง):
- Entry = ราคาปิดแท่งยืนยัน (strategy เข้าที่ราคาเปิดแท่งถัดไป)
- SL (default "เลยไส้หรือเส้น") = จุดที่ไกลกว่าระหว่างขอบเส้น กับ low/high ของแท่งยืนยัน (ซื้อ = ต่ำกว่า, ขายกลับกัน) เผื่อ `slBufferAtr` = 0 (ตำราไม่กำหนดระยะเผื่อ)
  ตัวเลือกอื่น: "เลยเส้น" อย่างเดียว / "เลยไส้แท่งยืนยัน" อย่างเดียว
- TP (default "เส้น fresh ถัดไป") = เส้น **fresh** ฝั่งตรงข้ามที่ใกล้ที่สุดตามทิศ — **ไม่มีเส้น fresh = ไม่เข้า** (ตำราไม่มีวิธีสำรอง)
  ตัวเลือก "RR คงที่" ไว้เทียบเท่านั้น ไม่ใช่ตำรา MSNR
- RR ขั้นต่ำ default **2** (crowinvesting: อย่างน้อย 1:2 ดีสุด 1:3–1:4) ต่ำกว่านี้ไม่เข้า
- ติดตามผลต่อจนชน SL หรือ TP เสมอ (ไม่หมดอายุตามความยาวกล่อง) — ชนทั้งคู่แท่งเดียวนับ SL, ชนะ ✔ / แพ้ ✘ ในตาราง
- กล่องแดง (entry↔SL) + เขียว (entry↔TP) ยาว `tradeBars` แท่งที่วาด + ป้าย `ET : .. SL : .. TP : .. RR : ..`
- ตัวกรอง storyline: ทิศ "ยังไม่ชัด" = **ไม่ขึ้นสัญญาณเลย** (เดิมขึ้นทั้งสองฝั่ง — แก้ตามตำรา "โครงสร้างไม่ชัด = ไม่เทรด")
- ไม่คำนวณ Lot (ไม่ได้ขอ)

**Trendline** (default เปิด) — จาก pivot ราคาปิดของ TF คำนวณเส้น (`pivotLen` เดียวกับเส้น): ก้น 2 จุดล่าสุดที่ยกตัว = เส้นแนวรับ,
ยอด 2 จุดล่าสุดที่ต่ำลง = เส้นแนวต้าน (เส้นละ 1 เส้น pivot ใหม่ลบเส้นเก่า) — ไส้แตะครั้งแรกหลังจุดที่ 2 = "แตะครั้งที่ 3" ป้าย `TL`
(ถ้าแท่งนั้นแตะเส้น MSNR ฝั่งเดียวกันด้วย = `TL+` confluence) — ราคาปิดทะลุ = จบเส้น หยุดยืด
ตอนสร้างเส้นจะ replay แท่งระหว่าง pivot กับตอนยืนยัน (ข้ามแท่งกลับตัว) กันพลาดการทะลุ/แตะ
ป้าย TL ขึ้นที่แท่งชาร์ตที่ประมวลผลแท่ง TF คำนวณเส้น (ช้ากว่าแท่งจริง 1 แท่ง เหมือนเส้นทั้งหมด)

**Liquidity** — เส้นประจุด high/low ของวัน/สัปดาห์/เดือนก่อน (PDH/PDL default เปิด, PWH/PWL เปิด, PMH/PML ปิด) จากต้นช่วงปัจจุบัน
ไม่แสดงถ้า TF ชาร์ต ≥ ช่วงนั้น วาดใหม่ที่แท่งสุดท้ายเท่านั้น (ประวัติย้อนหลังไม่วาด)
