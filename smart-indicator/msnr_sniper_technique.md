โค้ด: `src/msnr_sniper.pine` (indicator) + `src/msnr_sniper_strategy.pine` (สำเนาที่ส่งออเดอร์จำลองเพื่อดูผลใน Strategy Tester — ต้องแก้คู่กันเสมอ ต่างกันแค่หัว `strategy()` กับบรรทัดส่งออเดอร์)
ที่มา: คลิป "รีด RR ขั้นสุดด้วยเทคนิค MSNR" + คำบรรยายที่ผู้ใช้ส่งมา — รายละเอียดสิ่งที่ได้ยินและเห็นอยู่ใน `msnr_video_notes.md`
ผู้ใช้สั่ง (2026-10-17): **ไม่เอาเรื่องฟีโบ**, ลืมงานเก่า (`msnr.pine` เดิมไม่ถูกแตะ) — ไฟล์นี้เป็นอินดิเคเตอร์ตัวใหม่แยกไฟล์

## ขั้นตอนของระบบ (ตามที่คลิปสอน)

1. หาเส้นแนวรับ/แนวต้านจาก**ราคาปิด**บนไทม์เฟรมเส้น เก็บเฉพาะเส้นที่ **fresh** (ยังไม่เคยโดนไส้จิ้ม)
2. รอราคาชนเส้น fresh ที่ตรงด้าน (แตะแนวรับ → รอซื้อ, แตะแนวต้าน → รอขาย)
3. รอ **MSS** บนกราฟที่เปิด (ราคาปิดทะลุยอดย่อยล่าสุด = ซื้อ / ทะลุก้นย่อยล่าสุด = ขาย)
4. เข้าที่ราคาปิดของแท่ง MSS
5. **SL** = จุดต่ำสุด (ขายคือสูงสุด) ตั้งแต่แตะเส้น  **TP** = ยอดย่อย (ขายคือก้นย่อย) ของ**ไทม์เฟรมเส้น (กราฟใหญ่)** ที่ใกล้สุดฝั่งกำไร (ผู้ใช้เลือก 2026-10-17)

## ตารางที่มาของทุกกฎ

**[คลิป]** = ผู้พูดพูด/ภาพในคลิปแสดงชัด · **[ตีความ]** = คลิปพูดแนวคิดแต่ไม่ระบุรายละเอียด ผมกำหนดนิยามเอง · **[ผมคิดเอง]** = คลิปไม่ได้พูด ใส่เพื่อให้โค้ดทำงาน (ปรับได้ในหน้าตั้งค่า)

| กฎ / ค่าเริ่มต้น | สถานะ | หมายเหตุ |
|---|---|---|
| วาดเส้นจากราคาปิดไม่ใช่ไส้ เส้น A/V ที่ยอด/ก้นแหลมของกราฟเส้น | [คลิป] | ได้ยิน + เห็นภาพที่นาที 1:50 (วงกลมที่ยอดบนกราฟเส้น) |
| ยืนยันยอด/ก้นด้วย 3 แท่งซ้าย-ขวา (`pivotLen`) | **[ผมคิดเอง]** | คลิปไม่ระบุ — ใช้ 3 (ค่าตามอินดิเคเตอร์ชุมชน) |
| Open Close: ราคาปิดแท่งหนึ่งอยู่ "ใกล้" ราคาเปิดแท่งถัดไป (ลง→ขึ้น = แนวรับ, ขึ้น→ลง = แนวต้าน) | [คลิป] | ได้ยิน + เห็นเส้นที่นาที 3:42 |
| ระยะ "ใกล้กัน" ≤ 0.15×ATR และราคาเส้น = ราคาปิดแท่งแรก | **[ผมคิดเอง]** | คลิปไม่ระบุระยะ/ราคาเส้น |
| เบรกต้องเป็นเนื้อเทียน (ปิดเลยเส้น) ไส้ทะลุไม่นับ | [คลิป] | ได้ยินชัด |
| ทะลุแล้วกลับหน้าที่ (SBR / RBS) และกลับเป็น fresh | [คลิป] | ได้ยินชัด |
| โดนไส้จิ้ม 1 ครั้ง = unfresh ใช้ไม่ได้ จนกว่าเนื้อเทียนเบรก | [คลิป] | ได้ยินชัด + เห็นเส้นแดง (unfresh) |
| ไส้ของแท่งข้างๆ ยอด/ก้นที่ยืนยันภายหลังไม่นับเป็นการจิ้ม (นับจากแท่งที่ 2 หลังจุดกลับตัว) | **[ผมคิดเอง]** | ไม่งั้นเส้นทุกเส้นจะ unfresh ทันที |
| ไทม์เฟรมเส้น default = 60 (1 ชั่วโมง) | [ตีความ] | ตัวอย่างในคลิปใช้ W / 4H / 1H |
| แตะ = ไส้ถึงเส้นแต่ราคาปิดกลับฝั่งเดิม | [ตีความ] | คลิปพูด "จิ้ม point แล้วมีรีเจค" |
| MSS = ปิดเลยยอดย่อย/ก้นย่อยล่าสุด (ยอดแรกที่เกิดหลังแตะ ถ้ามี) | [ตีความ] | คลิปพูด "เนื้อเทียนที่เบรกขึ้นไป" — ไม่ได้นิยามยอดไหน |
| ยอด/ก้นย่อย = 2 แท่งซ้าย-ขวา, รอ MSS นานสุด 80 แท่ง | **[ผมคิดเอง]** | คลิปไม่ระบุ |
| เข้าที่ราคาปิดแท่ง MSS | [ตีความ] | คลิป: เข้าหลัง MS / ที่เนื้อเทียนที่เบรก |
| SL = จุดต่ำสุดตั้งแต่แตะเส้น (ขายคือสูงสุด) เผื่อ 0 | [คลิป] | ได้ยิน "low ด้านล่าง" + ภาพ SL สั้นมาก (0.4–7 pip) |
| TP = ยอดย่อยของ**ไทม์เฟรมเส้น** ที่ใกล้สุดเหนือจุดเข้า (ขาย: ก้นย่อยใต้จุดเข้า) | [ตีความ] + ผู้ใช้เลือก | คลิป: "สวิงไฮ ใกล้ๆ หรือตามที่วิเคราะห์จากกราฟใหญ่ก็ได้" — ผู้ใช้เลือกแบบกราฟใหญ่ หลังเห็นว่าแบบยอดย่อยของกราฟที่เปิดให้ TP ห่างจุดเข้า 0.19 ดอลลาร์ |
| ยอด/ก้นย่อยของกราฟเส้น = 2 แท่งซ้าย-ขวา (`tpSwingLen`) | **[ผมคิดเอง]** | คลิปไม่ระบุ |
| ไม่มียอด/ก้นให้เป็น TP = ไม่เข้า | **[ผมคิดเอง]** | คลิปไม่ได้พูด |
| RR ขั้นสุดต่ำ = 0 (ไม่กรอง) | — | คลิปไม่กำหนด (ผู้พูดใช้ RR 7–60 เท่าตามที่ลากเป้า) |
| strategy: เปิดทีละ 1 ไม้, ชน SL/TP ในแท่งเดียวนับ SL, ค่าธรรมเนียม 0.20 ต่อข้างต่อออนซ์ | **[ผมคิดเอง]** | ประมาณสเปรดทอง — ควรตรวจกับ broker จริง |
| จำนวนเส้นที่แสดง 6 ต่อฝั่ง, เก็บ 150 เส้น | **[ผมคิดเอง]** | แสดงผลเท่านั้น |

## สิ่งที่ "ยังไม่ได้ทำ" (ตั้งใจ)
- ฟีโบ 50% / โซน discount (ผู้ใช้สั่งตัด) — แปลว่าระบบนี้**เลือกจุดเข้าหลวมกว่าคลิป**: คลิปเลือกเฉพาะเส้น fresh ที่อยู่ในโซนราคาถูก ที่นี่เอาเส้น fresh ทุกเส้น
- โมเดล AMD / FVG / liquidity (ผู้พูดใช้เลือกทิศและเป้า — ทำเป็นกฎตายตัวไม่ได้)
- รวมเส้นที่อยู่ใกล้กันเป็นโซนเดียว, เข้าตอนแตะเลยแบบ "advanced", ขึ้นไปใช้ TF ที่สูงกว่าเมื่อภาพไม่ชัด, ย้าย SL ไปหน้าทุน (BE)
- เทรดเดี่ยวทีละไม้แบบมีวิจารณญาณของผู้พูด — โค้ดทำเป็นกฎตายตัว ผลจึงอาจต่างจากเคสที่ผู้พูดเลือกมาโชว์

## จุดที่คลิปขัดกันเอง (ต้องรู้)
- ตัวอย่างที่ 2: คำบรรยายผมอ่านว่า "โฟกัสซื้อ" แต่ภาพเป็นตำแหน่งขาย (SL 15.1 pip, เป้า 100.6 pip, RR 6.66) แล้วค่อยกลับมาซื้อที่ก้นด้วย SL 0.4 pip
- ตัวอย่างที่ 2 ตามภาพโดน SL (−1R) ก่อนราคาพุ่ง แต่ผู้พูดบอก "โดน BE"

## ข้อควรระวังเวลาทดสอบ
- Essential ดูกราฟเล็กย้อนหลังได้สั้น (5 นาทีราว 2 เดือน, 15 นาทีราว 6 เดือน) ตัวอย่างเทรดจะน้อย
- SL สั้นมาก ค่าสเปรดมีผลมาก
- ผลย้อนหลังไม่รับประกันอนาคต ผมไม่ใช่ที่ปรึกษาการลงทุน

## ผลดูบนกราฟจริงครั้งแรก (2026-10-17, XAUUSD 5 นาที, เส้น 1 ชั่วโมง)
- compile ผ่าน ไม่มี error, เส้น fresh (เขียว) ขึ้นเป็นกลุ่มที่ ~4,164–4,168, ลูกศร MSS ขึ้นทั้งซื้อ (เขียวน้ำเงิน) และขาย (ส้ม)
- **ปัญหาที่เห็น:** จุดเข้าหนึ่งจุดมีป้าย `ET 4159.690 / SL 4147.160 / TP 4159.880 / RR 0` — TP อยู่เหนือจุดเข้าแค่ 0.19 ดอลลาร์ ขณะที่ SL ห่าง 12.5 ดอลลาร์ (ชนะ ✔ แต่กำไรจริงไม่คุ้มสเปรด)
  สาเหตุ: กฎ TP ที่ผมตั้ง ("ยอดย่อยที่ใกล้สุดเหนือจุดเข้า บนกราฟที่เปิด") ถ้ามียอดย่อยเล็กๆ ใกล้จุดเข้า ก็ใช้ยอดนั้นเป็นเป้า — เป็น [ตีความ] ของผม ไม่ใช่สิ่งที่คลิปพูดตรงๆ (คลิป: "สวิงไฮใกล้ๆ หรือตามที่วิเคราะห์จากกราฟใหญ่")
- ลูกศร MSS ที่ไม่มีกล่องตามมา = ไม่มียอด/ก้นย่อยให้เป็น TP (ตามกฎ "ไม่มีเป้า = ไม่เข้า")
- ยังไม่ได้รันทดสอบกำไร/ขาดทุน (รอผู้ใช้ยืนยันนิยาม TP ก่อน)

**อัปเดต 2026-10-17:** เปลี่ยน TP เป็นยอด/ก้นย่อยของไทม์เฟรมเส้น (กราฟ 1 ชั่วโมง default) ตามที่ผู้ใช้เลือก — ยังไม่ได้ดูบนกราฟ ยังไม่ได้รันทดสอบ
