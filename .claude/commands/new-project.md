description: สร้างโปรเจกต์ใหม่ใน C:\dev ตามธรรมนูญ (ชื่อ + ชนิด + คำอธิบาย)
---

ผู้ใช้ขอสร้างโปรเจกต์ใหม่: $ARGUMENTS

ทำตามนี้:

1. แยก argument เป็น ชื่อ / ชนิด / คำอธิบาย
   - ชนิดที่รองรับ: `web` (Vite+TS), `next`, `node`, `python`, `blank`
   - ถ้าผู้ใช้ไม่ได้บอกชนิด ให้เดาจากคำอธิบาย แล้ว**บอกผู้ใช้ว่าเลือกอะไรและทำไม**
   - ถ้าชื่อไม่ใช่ kebab-case ให้แปลงให้ แล้วบอกชื่อที่จะใช้
2. รันสคริปต์ (ห้ามสร้างโฟลเดอร์เอง):

```
powershell -File C:\dev\.workspace\bin\new-project.ps1 -Name <ชื่อ> -Type <ชนิด> -Description "<คำอธิบาย>"
```

3. ถ้าสคริปต์ error ให้อ่าน error แล้วแก้ อย่ารันซ้ำเฉยๆ
4. เมื่อสำเร็จ: เขียน `CLAUDE.md` ของโปรเจกต์ใหม่ให้สมบูรณ์ตามที่ผู้ใช้อธิบาย
   (ส่วน "โปรเจกต์นี้คืออะไร", "โครงสร้าง", "กฎเฉพาะ") — อย่าปล่อยเป็น placeholder
5. สรุปให้ผู้ใช้เป็นภาษาไทย: path, พอร์ต, คำสั่งรัน, และขั้นถัดไป
