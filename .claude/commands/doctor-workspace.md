---

รัน:

```
powershell -File C:\dev\.workspace\bin\doctor.ps1
```

แล้ว:

1. อ่านผลลัพธ์ สรุปเป็นภาษาไทยว่าประเทศสุขภาพดีแค่ไหน
2. เรียงปัญหาตามความร้ายแรง — ปัญหาที่ขึ้นต้นด้วย `!!` (secret หลุดเข้า git) คือเรื่องด่วนที่สุด
   ต้องเตือนก่อนเรื่องอื่นทั้งหมด
3. เสนอวิธีแก้ทีละข้อ **แต่อย่าเพิ่งแก้** จนกว่าผู้ใช้จะบอก
   ยกเว้นการเติมไฟล์ที่ขาด (`CLAUDE.md`, `README.md`, `.gitignore`) แก้ได้เลยถ้าผู้ใช้สั่งรวมๆ ว่า "แก้ให้หน่อย"
4. ห้ามแก้ประวัติ git หรือลบไฟล์ใดๆ โดยไม่ถามก่อน
