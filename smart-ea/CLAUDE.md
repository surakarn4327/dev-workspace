## โปรเจกต์นี้คืออะไร

EA (Expert Advisor) เทรด forex อัตโนมัติ ใช้กับ broker Exness

- แพลตฟอร์ม: **MT5 (MQL5)** — ตัดสินใจแล้ว (2026-09-04) เหตุผล: ใหม่กว่า MT4, Exness รองรับเต็ม,
  MQL5 เขียนโค้ดยืดหยุ่นกว่า (OOP, มี built-in indicator เยอะกว่า) EA ทั้งหมดในโปรเจกต์นี้เขียนเป็น
  `.mq5` เท่านั้น
- โปรเจกต์พี่น้อง: [`ma-ribbon`](../ma-ribbon/CLAUDE.md) เก็บ Pine indicator ต้นฉบับของกลยุทธ์เดียวกัน
  ฝั่งนั้นเป็น Pine บน TradingView ฝั่งนี้เป็น MT5 ที่เทรดจริงและ backtest ได้
  **ห้าม import ข้ามโฟลเดอร์โปรเจกต์** (ตามธรรมนูญ) ถ้าต้องเทียบตรรกะให้อ่านไฟล์ แล้วเขียนซ้ำฝั่งนี้เอง

## คำสั่งที่ใช้จริง

MQL ไม่มี dev server — compile ด้วย MetaEditor แล้วแนบ EA เข้ากับ chart ใน MetaTrader
Strategy Tester ใช้ backtest ได้โดยไม่ต้องเทรดเงินจริง

compile จากคอมมานด์ไลน์ได้ ไม่ต้องเปิด GUI:

```bash
"C:\Program Files\MetaTrader 5 EXNESS\metaeditor64.exe" /compile:"C:\dev\smart-ea\src\sats\BestSATS.mq5" /log:"%TEMP%\c.log"
```

process คืนค่าก่อนเขียน log เสร็จ — รอสัก 5 วินาทีแล้วค่อยอ่าน log หา `Result: 0 errors`

## กฎ EA ของผู้ใช้ — บังคับทุกตัว ทุกครั้งที่พอร์ต EA ใหม่ (ตกลงกัน 2026-09-14)

**นี่คือกฎมาตรฐานของทุก EA ในโปรเจกต์นี้ ไม่ใช่ข้อเสนอแนะ ไม่ใช่ EA แยกต่างหาก** — เวลาพอร์ตกลยุทธ์ใหม่

1. **Day-trade/scalping เท่านั้น ห้ามถือไม้ข้ามคืน** — เปิดคอมได้แค่ 06:00–24:00 เวลาไทย ไม่มี VPS
   ต้อง `#include "PositionLib.mqh"` (หรือ implement `PastCutoff()` เองถ้า core ไม่ได้ใช้ PositionLib
   แบบ `AmdPo3Core.mqh`) แล้วเรียก `PL_PastCutoff(InpCutoffServerHour)` โดย**ต้องห่อด้วย `InpUseCutoff &&`
   เสมอ** (ดูข้อ 2) **ทั้งสองจุด**: (ก) guard ก่อนเปิดไม้ใหม่ทุกจุดที่เปิดไม้ (ข) บังคับปิดไม้ที่เหลือใน
   `OnTick()` ทันทีที่เลย cutoff — ดูโค้ดจริงใน `SelfAwareTrendCore.mqh`/`AmdPo3Core.mqh` เป็นตัวอย่างอ้างอิง
2. **ต้องมี input `InpUseCutoff` (bool, default true) คู่กับ `InpCutoffServerHour` (default 17) เสมอ**
   ในทุกไฟล์ `.mq5` ที่ EA ตัวนั้นเปิดไม้เอง — `InpUseCutoff=false` ต้องปิดกฎคัตไม้ทั้งหมดได้ (ทั้งปิดไม้
   บังคับและ guard ห้ามเปิดใหม่) ไม่ใช่แค่ปรับเวลา ผู้ใช้ขอไว้ 2026-09-14 ว่าต้องเลือกปิดกฎนี้ได้ทั้งบาน
   (default 17 ของ `InpCutoffServerHour` มาจากการวัดจริง 2026-09-14 ว่า server ของ Exness ช้ากว่าเวลาไทย
   7 ชม. — **ถ้า broker/บัญชีเปลี่ยนไปวัดใหม่เสมอ อย่าใช้ 17 เป็นค่าตายตัวข้ามบัญชี**)
3. **ช่อง `input` ทุกตัวต้องมีคอมเมนต์ภาษาไทยที่เข้าใจง่าย** ไม่ใช่แค่ชื่อตัวแปรภาษาอังกฤษเปล่าๆ —

4. **ต้องมี 3 โหมด TP เสมอ**: **Fix RR** (เป้าเดียว ปิดทีเดียว ไม่แบ่งปิด) · **Fix Multiple RR**
   (แบ่งปิดหลายเป้าตามระยะ R คงที่) · **Dynamic RR** (ปรับ R ตาม indicator/volatility ของกลยุทธ์นั้น)
   — สามโหมดนี้เป็น enum เดียว ไม่ใช่แค่ 2 โหมดแบบเดิม (Fixed/Dynamic ของ SATS ตอนนี้ยังไม่ครบ 3
   ต้องรีแฟกเตอร์เพิ่ม `SATS_TP_SINGLE` ทีหลัง — ดู TODO ท้ายไฟล์นี้)
5. **สูตรให้คะแนน optimize ต้องมี `InpMinTrades` เสมอ** (`ConsistencyScore()` ใน `TesterMetrics.mqh`
