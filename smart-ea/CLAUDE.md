# smart-ea

> อยู่ใต้ธรรมนูญ `C:\dev\CLAUDE.md` — อ่านไฟล์นั้นก่อน กฎในไฟล์นี้ชนะเมื่อขัดกัน

## โปรเจกต์นี้คืออะไร

EA (Expert Advisor) เทรด forex อัตโนมัติ ใช้กับ broker Exness

- แพลตฟอร์ม: **MT5 (MQL5)** — ตัดสินใจแล้ว (2026-09-04) เหตุผล: ใหม่กว่า MT4, Exness รองรับเต็ม,
  MQL5 เขียนโค้ดยืดหยุ่นกว่า (OOP, มี built-in indicator เยอะกว่า) EA ทั้งหมดในโปรเจกต์นี้เขียนเป็น
  `.mq5` เท่านั้น
- โปรเจกต์พี่น้อง: [`ma-ribbon`](../ma-ribbon/CLAUDE.md) เก็บ Pine indicator ต้นฉบับของกลยุทธ์เดียวกัน
  ฝั่งนั้นเป็น Pine บน TradingView ฝั่งนี้เป็น MT5 ที่เทรดจริงและ backtest ได้
  **ห้าม import ข้ามโฟลเดอร์โปรเจกต์** (ตามธรรมนูญ) ถ้าต้องเทียบตรรกะให้อ่านไฟล์ แล้วเขียนซ้ำฝั่งนี้เอง

## คำสั่งที่ใช้จริง

MQL ไม่มี dev server — compile ด้วย MetaEditor แล้วแนบ EA เข้ากับ chart ใน MetaTrader
Strategy Tester ใช้ backtest ได้โดยไม่ต้องเทรดเงินจริง

compile จากคอมมานด์ไลน์ได้ ไม่ต้องเปิด GUI:

```bash
"C:\Program Files\MetaTrader 5 EXNESS\metaeditor64.exe" /compile:"C:\dev\smart-ea\src\MARibbonEA.mq5" /log:"%TEMP%\c.log"
```

process คืนค่าก่อนเขียน log เสร็จ — รอสัก 5 วินาทีแล้วค่อยอ่าน log หา `Result: 0 errors`

## โครงสร้าง

- `src\MARibbonEA.mq5` — EA พอร์ตจาก Pine `MA Ribbon Signal + Stats` (ribbon MA cross, SL จาก ATR หรือ
  swing, TP1-TP3 เป็นตัวคูณ R, break-even ที่ TP1) ใช้ได้ทุกสัญลักษณ์/ทุก timeframe ตาม chart ที่แนบ

  - `InpRibbonShift` บวกเข้าทุกคาบทั้ง 13 เส้นเท่ากัน ระยะห่างระหว่างเส้นคงเดิม — จูน ribbon ด้วย
    ตัวแปรเดียวแทนที่จะไล่ทีละเส้น (ซึ่งเป็นล้านชุดและ overfit แน่นอน)
  - โหมดทบกำไร (`InpUseParlay`, ปิดไว้ default) — ไม้ที่ปิดด้วย `DEAL_REASON_TP` เท่านั้นถือว่าชนะ
    กำไรสุทธิของไม้นั้นถูกยกไปเพิ่มทุนเสี่ยงให้ไม้ถัดไป **ไม้เดียว** แล้วกลับสู่ทุนฐานเสมอ ไม่ว่าไม้ที่ทบ
    จะจบยังไง (ปิดตามสัญญาณ/SL/BE ไม่นับว่าชนะ) — ตกลงกับผู้ใช้ไว้ 2026-09-10
  - `OnTester()` ให้คะแนน = กำไรสุทธิ ÷ ขาดทุนสูงสุด และตัดชุดที่ไม้น้อยเกินทิ้ง
    พร้อมเขียนผลของทุก pass เป็นไฟล์ CSV ลงโฟลเดอร์ Common

- `src\MARibbonVisual.mq5` — อินดิเคเตอร์คู่กับ `MARibbonEA` วาดค่าเฉลี่ยกลุ่มสั้น/กลุ่มยาว (สองเส้นที่ EA
  ใช้ตัดสินใจจริง ซึ่งไม่มีอยู่บนชาร์ตปกติ) แถบสีระหว่างเส้น และลูกศรตรงจุดตัด เทียบกับ `plotshape`
  ของ Pine ได้ตรงๆ EA แนบให้เองผ่าน `iCustom` + `ChartIndicatorAdd` เมื่อเปิด `InpShowVisuals`
  และอยู่ในโหมดที่มองเห็น (ชาร์ตจริง หรือ Strategy Tester แบบ visual) — backtest โหมดปกติไม่วาดอะไรเลย

- `optimizer\` — ชุดไล่หาค่าตั้งต้นที่ดีที่สุด: สคริปต์สั่ง MT5 จากคอมมานด์ไลน์, ไฟล์ `.set` ที่ระบุช่วง
  ค่าที่ไล่ และผลที่รันไปแล้ว **อ่าน [`optimizer\README.md`](optimizer/README.md) ก่อนรัน optimization
  ทุกครั้ง** — มีข้อจำกัดของ MT5 ที่ไม่ทำตามจะพังเงียบๆ

copy ทั้ง `.mq5` และ `.ex5` ไปที่ `MQL5\Experts\` ของ terminal
(อินดิเคเตอร์ไปที่ `MQL5\Indicators\` แทน — ไม่ copy ไป EA จะขึ้น `MARibbonVisual not found`)
ไฟล์ `.ex5` คือผลลัพธ์ compile อยู่ใน `.gitignore` ไม่เข้า repo

## กฎเฉพาะของโปรเจกต์นี้

- ห้ามใส่ API key / login / password ของ Exness ลงในโค้ดหรือ commit ใดๆ เด็ดขาด
  (ตาม [ธรรมนูญข้อ 4](../CLAUDE.md)) ถ้า EA ต้องต่อ API ภายนอก ให้อ่านค่าจากไฟล์ config
  ที่ไม่เข้า git เท่านั้น
- ก่อนรันด้วยเงินจริงทุกครั้ง ต้อง backtest ผ่าน Strategy Tester และ/หรือทดสอบบนบัญชี demo ก่อนเสมอ
- Exness สมัครฟรี ไม่ผูกบัตร (ตรงตามกฎข้อ 4) — แต่การเติมเงินเข้าบัญชีเทรดจริงเป็นเรื่องการเงิน
  ที่ Claude ห้ามทำแทนผู้ใช้ (ดูกฎ "การกระทำต้องห้าม" ของระบบ) ผู้ใช้ต้องทำเองทุกขั้นตอนที่เกี่ยวกับเงิน
- **เจอผลลัพธ์ผิดปกติ (เช่น backtest ได้ 0 trades, PF/winrate เพี้ยนผิดคาด) ห้ามเดาสาเหตุแล้วแก้เลย**
  ต้องใส่ diagnostic counter/log เข้าไปในโค้ดก่อน (นับว่าทุกเงื่อนไข/ทุกจุด early-return โดนตัดออกกี่ครั้ง)
  รันแล้วดู log จริงว่าไปตายที่จุดไหนมากสุด ค่อยแก้ตรงจุดนั้นตามข้อมูลจริง — เหตุผล: 2026-09-04 แก้ EA
  แบบเดาสาเหตุ 2 รอบติด (ผ่อนเงื่อนไข breakout, แก้ full-body requirement) ไม่ได้ผลเพราะเดาผิดจุด
  พอใส่ counter (`gCnt_*` + `PrintFormat` ใน `OnDeinit`) ถึงเจอตัวการจริง (z-score ATR ที่ไม่ได้ log-transform
  ก่อน ทำให้ squeeze แทบไม่เกิด) ใส่ counter ไว้ก่อนเสมอเมื่อ debug entry/exit logic ของ EA
- **ผล optimization ที่ชนะแบบโดดเดี่ยว ห้ามเชื่อ** ต้องดูค่าข้างเคียงเสมอ ถ้าขยับพารามิเตอร์ 1 ขั้นแล้ว
  ผลตกฮวบ แปลว่าบังเอิญ ไม่ใช่ edge — เลือกค่าที่อยู่กลางแถบที่ดีทั้งแถบแทน (เจอจริง 2026-09-10:
  ribbon shift 19 ได้คะแนน 6.29 แต่ shift 18 กับ 20 ได้ 0.88 กับ 2.28)
