# optimizer — ไล่หาค่าตั้งต้นที่ดีที่สุดของ MARibbonEA

ทุกอย่างที่ต้องใช้ในการรัน optimization ซ้ำบนเครื่องไหนก็ได้ อยู่ในโฟลเดอร์นี้

```
optimizer\
├── bin\run-opt.ps1   ← สคริปต์สั่ง MT5 รันจากคอมมานด์ไลน์ แล้วเก็บผลเป็น CSV
├── sets\*.set        ← ช่วงค่าที่ไล่หาในแต่ละรอบ
└── results\*.csv     ← ผลที่รันไปแล้ว
```

ตัดช่วงให้สั้นลงเองโดยไม่บอก ตรวจได้จาก Journal บรรทัด `history data begins from ...`

ข้อมูลระดับ tick จริงมีย้อนหลังแค่ประมาณ 8 เดือน จึงต้องใช้โมเดล **1 minute OHLC** ถ้าอยากได้ครบ 1 ปี

### 4. ตั้งค่าใน Strategy Tester ครั้งเดียว (สำคัญที่สุด)

**ช่องพวกนี้สั่งจากคอมมานด์ไลน์ไม่ได้** MT5 จะใช้ค่าที่บันทึกไว้ใน GUI เสมอ ตั้งครั้งเดียวใช้ได้ตลอด

| ช่อง | ตั้งเป็น |
|---|---|
| Symbol | `XAUUSDm` |
| Date | **`Custom period`** (ห้ามเป็น preset อย่าง `Last year`) |
| ช่วงวันที่ | `2568.09.10` ถึง `2569.09.08` |
| Forward | `No` |
| Delays | `35 ms` |
| Modelling | **`1 minute OHLC`** |
| Deposit | `10000` USD, leverage `1:100` |
| Optimization | `Fast genetic based algorithm` |
| เกณฑ์ (ช่องขวาของ Optimization) | **`Custom max`** |

`Custom max` คือค่าที่ `OnTester()` ใน EA คืนมา = กำไรสุทธิ ÷ ขาดทุนสูงสุด และให้ 0 กับชุดที่
เข้าไม้ไม่ถึง `InpMinTrades` หรือขาดทุน — ถ้าไม่เลือกช่องนี้ ผลที่ได้จะเป็นชุดที่เข้าไม้ 4 ครั้งแล้วฟลุกกำไร

**ปิด MT5** ก่อนสั่งสคริปต์ทุกครั้ง

## รูปแบบไฟล์ผล

คั่นด้วย `;` ไม่มีหัวคอลัมน์ (แต่ละ pass เขียนมาจาก `DumpPass()` ใน EA)

รอบแรก (`stage1_*.csv`) 15 คอลัมน์:

```
symbol; timeframe; ใช้ATR; atrMult; โหมดTP; TP1; TP2; TP3; BE;
ไม้; กำไรสุทธิ; ขาดทุนสูงสุด; PF; กำไรเฉลี่ยต่อไม้; คะแนน
```

รอบสอง (`stage2_*.csv`) แทรก 3 คอลัมน์หลัง BE:

```
... BE; เลื่อนคาบ ribbon; ชนิดเส้น MA; จำนวนแท่ง swing; ไม้; ...
```

`โหมดTP`: 0 = แบ่งปิด 3 ไม้ย่อย, 1 = ปิดครั้งเดียวที่ TP3, 2 = ไม่ใช้ TP
`ชนิดเส้น MA`: 0 = SMA, 1 = EMA, 2 = SMMA (เท่ากับ RMA ของ Pine), 3 = LWMA

**ระวังตอนอ่าน** — พารามิเตอร์บางตัวไม่ถูกใช้ในบางโหมด ค่าที่เห็นจึงไม่มีความหมาย:
- `atrMult` ไม่มีผลเมื่อ `ใช้ATR = 0` (SL มาจาก swing high/low แทน)
- `TP2` ไม่มีผลเมื่อ `โหมดTP = 1`
- `TP1/TP2/TP3` ไม่มีผลเลยเมื่อ `โหมดTP = 2` และถ้า `BE = 0` ด้วย ก็ไม่เหลือตัวไหนมีผล

ทำให้หลายแถวที่ดูต่างกัน จริงๆ เป็นชุดเดียวกัน — MT5 ไม่รู้เรื่องนี้จึงเสียรอบไปกับชุดซ้ำ
เวลาตั้งช่วงค้นหารอบใหม่ ควรแยกกิ่ง (เช่น รันเฉพาะ swing รอบหนึ่ง เฉพาะ ATR อีกรอบหนึ่ง)

## สิ่งที่รู้แล้วจากรอบที่ผ่านมา

- **M15 ดีที่สุด** M5 กำไรได้แต่ขาดทุนสูงสุดเกือบเท่าพอร์ต **M1 ไม่มีสักชุดที่กำไรจาก 111 ชุด**
  (เข้าไม้ 3,000–5,700 ครั้งต่อปี ค่าสเปรดกินหมด)
- เลื่อนคาบ ribbon ช่วยได้จริง — M15 ชุดคะแนนสูงสุด เลื่อน +14 เปลี่ยนเป็น SMA แล้ว
  กำไรเพิ่ม 13% พร้อมขาดทุนสูงสุดลดลง 31%
- ชุดที่เลื่อนไปมากๆ จะเข้าไม้น้อยลงมาก (625 เหลือ 149 ไม้ต่อปี) คะแนนสวยขึ้นแต่เชื่อได้น้อยลง
  ให้ดูค่าข้างเคียงประกอบเสมอ ถ้า +13/+14/+15 ให้ผลใกล้กันจึงถือว่าเป็นที่ราบจริง
