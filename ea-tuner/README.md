# ea-tuner

โปรแกรม desktop (Python + Tkinter) ควบคุมการทดสอบ/จูน EA ของ MT5 ในโปรเจกต์พี่น้อง
[`../smart-ea`](../smart-ea/CLAUDE.md) — ไม่ต้องพิมพ์คอมมานด์ไลน์เอง ไม่ต้องเปิดไฟล์ `.set` เอง
เลือก EA แล้วกด **รัน** โปรแกรมจะสั่ง MT5 backtest/optimize ให้เองทั้งหมด แล้วเปิดหน้าสรุปผลให้อัตโนมัติ

## วิธีเปิดโปรแกรม

**ดับเบิลคลิกไฟล์ [`run.bat`](run.bat)** ในโฟลเดอร์นี้ — แค่นี้พอ ไม่ต้องพิมพ์อะไรเลย

ครั้งแรกอาจใช้เวลาสักครู่ (โปรแกรมเตรียมสภาพแวดล้อมให้เอง) ครั้งต่อไปเปิดเร็วปกติ ถ้าเครื่องยังไม่มี
Python จะขึ้นข้อความบอกให้ติดตั้งก่อน (`winget install Python.Python.3.12` แล้วดับเบิลคลิก `run.bat`
ใหม่อีกครั้ง)

<details>
<summary>ถ้าอยากรันผ่านคอมมานด์ไลน์แทน</summary>

```bash
cd ea-tuner
.\.venv\Scripts\python.exe src\main.py
```

(ถ้ายังไม่เคยสร้าง `.venv` มาก่อน ให้รัน `run.bat` ครั้งแรกก่อนเพื่อให้มันเตรียมให้)
</details>

## ก่อนใช้ครั้งแรก

1. **ปิด MT5 ให้สนิทก่อนกดรันทุกครั้ง** — ถ้าเปิด MT5 ค้างไว้ โปรแกรมจะรันไม่ได้
2. EA ที่จะทดสอบต้อง compile + copy ไฟล์ `.ex5` ไปที่ `MQL5\Experts\Advisors\` ของ MT5 terminal
   มาก่อนแล้ว (ทำที่ฝั่ง `smart-ea` — ดู `smart-ea\CLAUDE.md`) โปรแกรมจะหาโฟลเดอร์ terminal ให้เอง
   จากตำแหน่งไฟล์ `.ex5` นั้น ถ้าหาไม่เจอจะขึ้น error บอกให้ไป compile+copy ก่อน
3. ต้องมีไฟล์ `.set` อย่างน้อย 1 ไฟล์ในโฟลเดอร์ `smart-ea\optimizer\sets\` ตรงกับ EA ที่จะจูน
   (ไฟล์ `.set` คือไฟล์กำหนดว่าจะจูนพารามิเตอร์ไหน ช่วงค่าเท่าไหร่) ถ้ายังไม่มี กดปุ่ม
   "แก้ไฟล์ .set" ในหน้าโปรแกรมเพื่อสร้างใหม่ได้เลย

## หน้าตาโปรแกรม — แต่ละช่องคืออะไร

| ช่อง | ทำอะไร |
|---|---|
| **EA** | เลือก EA ที่จะทดสอบ/จูน (รายการดึงมาจาก `smart-ea\src\*.mq5` อัตโนมัติ) |
| **.set** | ไฟล์กำหนดพารามิเตอร์ที่จะจูน — เดาให้ตาม EA ที่เลือกอัตโนมัติ ยังแก้เองได้ (กดปุ่ม "แก้ไฟล์ .set") |
| **สัญลักษณ์** | คู่เงิน/ทองที่จะเทรด เช่น `XAUUSDc` |
| **TF** | timeframe — เดาให้ตาม EA ที่เลือกอัตโนมัติ (เช่น EA ชื่อมี M5 ก็เดาเป็น M5) ยังแก้เองได้ |
| **เงินฝากตั้งต้น** | ทุนจำลองในการทดสอบ (USD) |
| **ความเสี่ยงต่อไม้** | เลือกโหมด "USD คงที่" หรือ "% ของ equity" แล้วใส่ตัวเลข |
| **ขนาด 1 จุด (point unit)** | ใช้คำนวณ lot size — เดาจากชื่อสัญลักษณ์ (ลงท้าย `c` = 1.0, อื่นๆ = 0.01) **แม่นแค่ทองเท่านั้น** คู่เงินอื่นต้องเช็คค่าจริงเองก่อน (ดูหัวข้อ "ขนาด 1 จุด" ด้านล่าง) |
| **ตั้งแต่วันที่ / ถึงวันที่** | ช่วงข้อมูลที่จะทดสอบ — **โหมดจูนล็อกให้อัตโนมัติ กดแก้เองไม่ได้** (ดูเหตุผลด้านล่าง) โหมดอื่นกรอกเองได้ |
| **โหมด** | รันเดี่ยว / จูน / จำลองถอนกำไรรายสัปดาห์ / รายเดือน (อธิบายแต่ละโหมดด้านล่าง) |

## 4 โหมดที่เลือกได้

### 1. รันเดี่ยว
ทดสอบชุดพารามิเตอร์เดียวตามที่ระบุใน `.set` (ค่า default ของแต่ละบรรทัด) บนช่วงวันที่ที่กรอกเอง
ใช้ตอนอยากดูผลของค่าที่รู้อยู่แล้วว่าจะใช้ ไม่ได้ค้นหาค่าใหม่

### 2. จูน (แนะนำให้ใช้ตัวนี้เป็นหลัก)
กดปุ่มเดียว โปรแกรมค้นหาค่าที่ดีที่สุดให้เองครบ 3 ขั้น ไม่ต้องยุ่งอะไรเพิ่ม:

1. **ค้นกว้าง (genetic) 3 รอบ** — สุ่มไล่ค่าตามช่วงที่กำหนดใน `.set` รันซ้ำ 3 รอบเพราะการสุ่มแต่ละ
   รอบอาจได้คำตอบไม่เหมือนกัน รวมผู้ชนะทั้ง 3 รอบเข้าด้วยกันแล้วเลือกตัวที่ดีที่สุด
2. **ตรวจสอบเพื่อนบ้าน (exhaustive)** — ไล่ค่าโดยรอบผู้ชนะจากขั้น 1 แบบละเอียดครบทุกจุด (ไม่ใช่สุ่ม)
   เพื่อเช็คว่าค่านั้นดีจริงเป็นบริเวณกว้าง ไม่ใช่ดีแค่จุดเดียวโดยบังเอิญ — **ค่าที่ควรใช้จริงมาจาก
   ขั้นนี้** ไม่ใช่ขั้น 1
3. **ตรวจสอบ holdout** — เอาค่าที่ผ่านขั้น 2 ไปทดสอบกับข้อมูลช่วงล่าสุด 45 วันที่**ไม่เคยถูกใช้เลือก
   ค่าเลย** ถ้าผลยังดีอยู่ = น่าเชื่อถือ ถ้าผลพัง = ค่าที่ได้ใช้ไม่ได้จริง (ห้ามเอาผลตรงนี้ไปเลือกค่าใหม่
   เด็ดขาด เพราะจะทำให้ไม่เหลือข้อมูลไว้ตรวจสอบอีกเลย)

ช่วงวันที่คำนวณอัตโนมัติเสมอ: **เริ่ม 1 ม.ค. 2568 ถึงสิ้นเดือนก่อนหน้าเดือนปัจจุบัน** (ตัดเดือนที่
กำลังเดินอยู่ทิ้งเพราะข้อมูลยังไม่ครบเดือน) แปลว่าถ้าเปิดโปรแกรมจูนใหม่เดือนหน้า ช่วงข้อมูลจะขยับตาม
วันที่ปัจจุบันเองอัตโนมัติ ไม่ต้องแก้อะไร

### 3. จำลองถอนกำไรรายสัปดาห์ / รายเดือน
รันทีละงวด (สัปดาห์/เดือน) แยกกัน โดย**รีเซ็ตทุนกลับเป็นค่าเริ่มต้นทุกครั้ง** — จำลองว่าถ้าถอนกำไร
ออกหมดทุกงวดจริง (ไม่ปล่อยให้ทบต้น) จะได้กำไรงวดละเท่าไหร่บ้าง เหมาะกับดูว่ารายได้ต่อเดือน/สัปดาห์
สม่ำเสมอแค่ไหน

## อ่านหน้าสรุปผลยังไง

รันเสร็จโปรแกรมจะเปิดหน้าเว็บสรุปผลให้เองในเบราว์เซอร์ (ไฟล์เก็บไว้ที่ `output/`) ประกอบด้วย:

- **ชุดที่แนะนำให้ใช้จริง** — สรุปตัวเลขของค่าที่ผ่านการตรวจสอบเพื่อนบ้านแล้ว (ไม่ใช่แค่ผู้ชนะรอบแรก)
- **ผลตรวจสอบเพื่อนบ้าน** — เทียบคะแนนรอบค้นกว้างกับรอบตรวจสอบ บอกว่าค่าที่ดีที่สุดขยับไปจากรอบแรก
  หรือเปล่า
- **ตรวจสอบ holdout** — ตารางเทียบผล train vs holdout พร้อมคำตัดสิน **"ผ่าน"/"ไม่ผ่าน"** ชัดเจน —
  ถ้าขึ้น "ไม่ผ่าน" **อย่าเอาค่านั้นไปใช้จริง** ให้ลองกับ EA/ช่วงค่าอื่น หรือส่งไฟล์รายงานนี้กลับมาให้
  Claude ช่วยดูว่าควรปรับตรรกะตรงไหน
- **กราฟกำไรรายงวด** — แท่งกำไร/ขาดทุนแต่ละเดือนหรือสัปดาห์
- **ตารางไล่ดูทุกชุดที่รัน** — กดหัวคอลัมน์เพื่อเรียงลำดับ ดูรายละเอียดทุกชุดที่เคยลองมา

## เรื่อง "ขนาด 1 จุด" (point unit) ที่ต้องระวัง

ค่านี้กระทบขนาด lot โดยตรง **ตั้งผิดแล้วความเสี่ยงจริงจะต่างจากที่ตั้งใจเป็นสิบ-ร้อยเท่าแบบเงียบๆ**
โปรแกรมเดาให้แบบหยาบมาก (แค่ดูว่าชื่อสัญลักษณ์ลงท้ายด้วย `c` หรือเปล่า) ซึ่ง**แม่นเฉพาะทองในบัญชีนี้
เท่านั้น**:

- ทอง บัญชีปกติ (เช่น `XAUUSDm`, `XAUUSD`) → `0.01`
- ทอง บัญชี Cent (เช่น `XAUUSDc`) → `1.0`
- **คู่เงินอื่นๆ ค่าไม่เหมือนกัน** ต้องรันสคริปต์ `SymbolInfoDump.mq5` ใน smart-ea เพื่อดู contract
  size จริงของสัญลักษณ์นั้น แล้วคำนวณเอง: `point unit = 1 / contract size` (ถ้า USD เป็น
  quote currency) หรือ `point unit = เรตปัจจุบัน / contract size` (ถ้า USD เป็น base currency
  เช่น USDJPY, USDCAD) — รายละเอียดเต็มอยู่ใน `smart-ea\bugs.md` หัวข้อ 2026-09-12

## สถานะ

สร้างเมื่อ 2026-09-12 — จูนแบบ 3 ขั้น (genetic × 3 รอบ + ตรวจสอบเพื่อนบ้าน + holdout) พร้อมความเสี่ยง/
point unit ปรับได้ในหน้าต่างหลัก, TF/`.set` เดาอัตโนมัติตาม EA, เปิดด้วย `run.bat` ดับเบิลคลิกเดียว
