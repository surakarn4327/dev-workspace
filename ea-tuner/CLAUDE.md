## โปรเจกต์นี้คืออะไร

โปรแกรม desktop (Python) ควบคุมการจูน/ทดสอบ EA ของ MT5 ในโปรเจกต์ smart-ea

## คำสั่งที่ใช้จริง

```bash
python src\main.py      # รัน dev (พอร์ต 8000)
# ไม่มี build step    # build
pytest     # test
```

หรือใช้ Browser pane: `preview_start` ชื่อ `ea-tuner`
