### คีย์ลัดตัวอักษรไม่ทำงานเมื่อเปิดแป้นพิมพ์ภาษาไทย
- **อาการ:** เปิดแป้นไทยแล้ว Ctrl+A/C/V/D, R, W, F, Ctrl+Z/Y, `[` `]` ไม่ตอบสนอง (ลูกศร/Delete/Esc ปกติ)
- **สาเหตุ:** โค้ดเทียบ `e.key` กับตัวอักษรละติน แต่แป้นไทยส่ง `e.key` เป็นตัวอักษรไทย (Ctrl+C = "แ")
- **วิธีแก้:** `keyName()` ใน `src/ui/workspace.ts` อ่านตัวอักษร/วงเล็บจากตำแหน่งปุ่ม `e.code` — คีย์ลัดใหม่ทุกตัวต้องผ่าน `keyName()` ห้ามใช้ `e.key` ตรงๆ กับตัวอักษร

### Push button ค้างกดหลังโหลดไฟล์เซฟ
- **อาการ:** ถ้าเซฟขณะกดปุ่มค้าง พอ reload หรือ import ปุ่มจะติดสถานะ pressed วงจรปิดตลอด
- **สาเหตุ:** `params.pressed` ถูก serialize ลงไฟล์เหมือน param ทั่วไป ทั้งที่เป็นสถานะชั่วคราวของเมาส์
- **วิธีแก้:** `World.load()` รีเซ็ตทุก param ชื่อ `pressed` เป็น `false` (`src/board/world.ts`) — ชิ้นส่วน momentary ใหม่ต้องใช้ชื่อ `pressed` ด้วย

### มุมมองแรกเข้าไม่ fit ตอนเปิดครั้งแรก
- **อาการ:** เปิดแอปครั้งแรก breadboard โผล่มุมซ้ายบนเล็กๆ ต้องกด Fit เอง
- **สาเหตุ:** `fitView()` ถูกเรียกใน `requestAnimationFrame` แรก ซึ่ง layout ของ canvas ยังไม่นิ่ง (ขนาด canvas ยังไม่ถูกวัด)
- **วิธีแก้:** หน่วง 80 ms ก่อนเรียก (`src/ui/app.ts`)

### Mission 6: สายจั๊มเสียบรูที่ไม่มีอยู่จริง
- **อาการ:** สายสีน้ำเงินของ mission "Current in series" ปลายไม่ต่อกับอะไร LED ไม่ครบวงจร
- **สาเหตุ:** อ้างแถว 8 ของ breadboard ซึ่งเป็นร่องกลาง (ไม่มีรู) — แถวที่มีรูคือ 0–1, 3–7, 10–14, 16–17
- **วิธีแก้:** เปลี่ยนไปต่อรางลบแถว 1 (`src/lessons/lessons.ts`) และเขียนเทสต์ที่สร้างเฉลยของทุก mission (`lessons.test.ts`) กันซ้ำ

### Mission 7: เช็กอัตราขยายไม่มีวันผ่าน
- **อาการ:** ต่อทรานซิสเตอร์ถูกต้องหมด LED ติด แต่ข้อสุดท้ายไม่ติ๊ก
- **สาเหตุ:** เงื่อนไข `Ic > 20 x Ib` แต่ทรานซิสเตอร์อิ่มตัว (LED+470R จำกัด Ic ≈ 14.5 mA, Ib ≈ 0.83 mA → อัตราส่วน ≈ 17) ทำให้ผ่านไม่ได้
- **วิธีแก้:** ลดเกณฑ์เป็น `> 10x` ที่ยังพิสูจน์ว่า "กระแสเล็กคุมกระแสใหญ่" ได้

### LED pixel ตอนดับมีพื้นที่ดำเป็นก้อน
- **อาการ:** สไปรต์ LED สถานะดับ ส่วนเงาตรงกลางและขวากลายเป็นสีดำสนิท
- **สาเหตุ:** `mix()` ใน `render/draw.ts` คืน `rgb(r,g,b)` แต่ parse อินพุตเป็น hex — เอาผลของ `mix` ไปผสมซ้ำจึงได้ NaN → ดำ
- **วิธีแก้:** แปลงฐานสีสถานะดับกลับเป็น hex ก่อนผสมต่อ (`ledSprite` ใน `src/parts/art.ts`)

### ขา LDR pixel ลอยห่างจากตัว
- **อาการ:** ขา 2 เส้นของ LDR อยู่ใต้ตัวกลมแต่ไม่แตะตัว
- **สาเหตุ:** ขาอยู่ที่ x = 0/40 แต่ตัวเป็นวงกลม ที่ตำแหน่งนั้นขอบวงกลมอยู่สูงกว่าก้นตัวมาก ขาที่เริ่มวาดจาก y = −10 จึงห่างจากตัว
- **วิธีแก้:** ให้ขาเฉียงเข้าไปซ่อนใต้ตัว (ผู้ใช้ขอขาเฉียง) วาดก่อนสไปรต์ให้ตัวบัง (`ldr` ใน `src/parts/passives.ts`) — ชิ้นส่วนกลมที่ขาไม่อยู่ตรงก้นต้องเช็กแบบเดียวกัน

### สายตามชิ้นส่วนแล้วจุดต่อ (taps) หลุดจากมุม
- **อาการ:** ย้ายชิ้นส่วน/บอร์ดที่มีสายต่ออยู่ แล้วบางครั้งสายมี `taps` ชี้จุดที่ไม่ใช่มุมของสายอีกต่อไป (fuzz เจอ 7 จาก 3000 ครั้ง)
- **สาเหตุ:** `followWire` เลื่อนปลาย `a` ไปทับจุด tap พอดี หรือ `tidy` ยุบมุมนั้นทิ้ง แต่ไม่ได้กรอง `taps` ตาม
- **วิธีแก้:** หลังจัดรูป กรอง `taps` ให้เหลือเฉพาะจุดที่ยังเป็นมุมใน `via` (`followWire` ใน `src/board/follow.ts`) — กฎ: `taps` ต้องเป็นสับเซตของ `via` เสมอหลังแก้รูปสายทุกครั้ง

### Logic gate ไม่ทำงานเมื่อมีแบตมากกว่า 1 ก้อนบนกระดาน
- **อาการ:** NOT gate ไฟสถานะเขียว (Y สูง) แต่ LED ที่ต่อกับ Y ได้กระแสแค่ ~12 nA ไม่ติด เกิดเมื่อมีแบต/supply อีกตัวบนกระดานที่ไม่ได้ใช้
- **สาเหตุ:** gate เป็นสัญลักษณ์ไม่มีขากราวด์ จึงอ้างอิงโหนด 0 ซึ่งคือขั้ว − ของแหล่งจ่าย "ตัวแรกในรายการชิ้นส่วน" ถ้าตัวแรกไม่ใช่แบตในวงจรเดียวกัน Y จึงไม่มีทางไหลกลับ
- **วิธีแก้:** gate อ้างอิงขั้ว − ของแหล่งจ่ายในวงจรเดียวกัน (`partRef` ใน `board/connectivity.ts`: โหนดที่เชื่อมกันผ่านชิ้นส่วนอื่น ไม่นับแหล่งจ่ายกับ gate) ไม่มีก็ใช้โหนด 0; `GateElement.ref` ใน `sim/solver.ts` — เทสต์ `gates.test.ts` "own circuit" — กฎ: ชิ้นส่วนที่ไม่มีขากราวด์ห้ามอิงโหนด 0 ตรงๆ

### ไฟล์ import ที่ถูกแก้มือทำให้ค่าผิดเงียบๆ / id ซ้ำ
- **อาการ:** ไฟล์ที่ใส่ตัวต้านทาน 0 หรือติดลบได้กระแส 0 แทนที่จะลัดวงจร, สายสองเส้น id เดียวกันผ่านการตรวจ, `counter` ต่ำกว่า id ที่ใช้อยู่ทำให้ชิ้นใหม่ id ชนของเดิม
- **สาเหตุ:** `validateWorldData` ตรวจแค่ชนิดข้อมูล ไม่ตรวจช่วงค่าตาม field ของชิ้นส่วน ไม่ตรวจ id สายซ้ำ ไม่ปรับตัวนับ id
- **วิธีแก้:** `sanitizeParams` (`parts/index.ts`) ดึงค่ากลับเข้าช่วงของ field (slider ตัดขอบ, ตัวเลือกต้อง > 0, toggle ต้องเป็น boolean ไม่งั้นใช้ค่า default) เรียกใน `save/storage.ts`; `validateWorldData` ปฏิเสธ id สายซ้ำและดัน `counter` ให้เกิน id ทั้งหมด — เทสต์ `save/storage.test.ts`

### จุดกระแสไหลของชิป 74HC ขึ้นบนสายอินพุตแทนสาย VCC
- **อาการ:** ต่อขาอินพุตของชิปเข้าขั้ว + ตรงๆ แล้วจุดกระแสไหลวิ่งบนสายอินพุต (ขา 1) แทนสายไฟเลี้ยง (ขา 14) ทั้งที่ขาอินพุตไม่ดึงกระแส
- **สาเหตุ:** `computeFlow` หาขาของชิ้นส่วนจากโหนดด้วย `nodes.indexOf(n)` ซึ่งคืนขาแรกที่อยู่บนโหนดนั้น ขา 1 กับขา 14 อยู่บนโหนดเดียวกัน (ต่อเข้า + ทั้งคู่) กระแสไฟเลี้ยงเลยถูกนับเป็นของขา 1
- **วิธีแก้:** กระแสที่องค์ประกอบ `C` ดึงจาก VCC/GND ผูกกับขา 14/7 ก่อนเสมอ (`board/flow.ts`) — เทสต์ "flowing dots run from the battery into VCC" ใน `board/ic.test.ts` — กฎ: ชิ้นส่วนที่หลายขาอาจอยู่โหนดเดียวกัน ห้ามหาขาจากโหนดด้วย `indexOf` เฉยๆ

### ภาพ pinout ของชิป: สายพาดทับสัญลักษณ์ gate และคำ VCC ถูกตัด
- **อาการ:** สายของ gate แถวบนพาดผ่าน gate แถวล่าง และคำ VCC เห็นแค่ครึ่งล่าง
- **สาเหตุ:** ตัวชิปสูงแค่ 88 แต่ต้องมี gate สองแถวพร้อมสายเข้า/ออก (ต้องการราว 92) สายเลยล้ำเข้าครึ่งของอีกแถว; canvas ไม่มีขอบบนพอสำหรับคำเหนือขา 14
- **วิธีแก้:** ตัวชิป 112 สูง แบ่งสองครึ่ง gate กับสายทุกเส้นของมันอยู่ในครึ่งตัวเอง (`GATE_Y`, `CHIP` ใน `ui/icSheet.ts`) และเลื่อนกรอบวาดให้เหลือขอบบน — กฎ: เปลี่ยนขนาดตัวชิปต้องเช็กว่าสองแถว gate ไม่ซ้อนกันในแนวตั้ง

### ข้อความสรุปของชิป 74HC ซ้ำชื่อรุ่น
- **อาการ:** แถบสถานะและ Inspector ขึ้น "74HC08 quad AND: 74HC08 quad AND: 4 gates..."
- **สาเหตุ:** `summary()` ใส่ชื่อรุ่นไว้แล้ว แต่ผู้เรียกใส่ชื่อชิ้นส่วนนำหน้าอยู่แล้ว
- **วิธีแก้:** `summary` ของชิปคืนแค่ "4 gates, VCC pin 14, GND pin 7" (`parts/ic.ts`)

### ป้ายค่า resistor ห่าง 4.7 ตอนหมุน 90°/270° (โหมดเวกเตอร์) และ harness รายงานผิด
- **อาการ:** `label-gap-harness` ได้ 4.7 ที่ resistor บางมุม และรายงานว่ากล่องป้ายของ gate เปลี่ยนรูปตอนหมุน
- **สาเหตุ:** resistor ตะแคงทำให้กล่องป้ายอยู่ข้างตัว คลุมช่วงกลางที่บางกว่าปลายมน แต่โค้ดวัดจากขอบปลายมน (−10); ส่วน gate: ตอนหมุน 270° ป้ายขาหนึ่งอันเลยขอบภาพของ harness (`OY` น้อยไป) จึงไม่ถูกนับ
- **วิธีแก้:** ใช้ −9.3 ตอนหมุนตะแคง (`parts/passives.ts`), `OY = 500` ใน `scripts/label-gap-harness.js` — กฎ: ผล harness ที่ "รูปเปลี่ยนตอนหมุน" ให้ตรวจก่อนว่าป้ายหลุดภาพ
