# wire-up

Virtual electronics lab: realistic circuit simulation with breadboard, instruments, Arduino and ESP32, plus mission-style lessons

## เริ่มใช้งาน

```bash
npm install
npm run dev -- --port 5173
```

เปิดที่ http://localhost:5173

```bash
npm run test    # solver + วงจรบน breadboard + เฉลยของทุก mission
npm run build   # tsc (strict) + vite build
```

## เพิ่มชิ้นส่วนใหม่

ดู [`PARTS.md`](PARTS.md) (ขั้นตอนบังคับ + `/new-part`) และหน้าดูชิ้นส่วนทั้งหมดที่ `/gallery.html` ตอนรัน `npm run dev`

## ทำอะไรได้ (v1 — วงจรไฟฟ้า)

- เลือกชิ้นส่วน/สายแล้วแผงขวาแสดง Inspector ให้เอง: ถ้าแผงซ่อนอยู่จะเลื่อนออกมา แล้วคลิกพื้นที่ว่างจะพับกลับ; ถ้าเปิดอยู่แล้วจะสลับเป็นแท็บ Inspector แล้วคลิกพื้นที่ว่างจะกลับแท็บเดิม (ถ้ากดแท็บหรือปุ่มแผงเองระหว่างนั้น ระบบจะไม่ยุ่ง)
- ชิป 74HC แบบ DIP-14 จริง 6 รุ่น (ขาอินพุตปล่อยลอย = เอาต์พุตกะพริบมั่ว, อินพุตเกินไฟเลี้ยงจนไดโอดป้องกันนำกระแสเกินพิกัด = ไหม้)
- (รายละเอียดชิป) (00 NAND, 02 NOR, 04 NOT, 08 AND, 32 OR, 86 XOR): ขา 14 = VCC, 7 = GND ต้องต่อไฟเลี้ยงเอง (2–6 V) คร่อมร่องกลาง breadboard ได้ ไฟเลี้ยงเกิน 7 V / ต่อกลับขั้ว / เอาต์พุตเกิน 25 mA = ไหม้
- จุดกระแสไหลวิ่งบนสายตามทิศกระแสจริง
- Logic gate 7 ตัว (NOT AND OR NAND NOR XOR XNOR) หมวด Logic: ขา A B Y ไม่มีขาไฟเลี้ยง สูง = 5 V สลับที่ 1.4 V ไม่มีวันไหม้ (เป็นสัญลักษณ์ ไม่ใช่ IC จริง)
- toolbox ด้านซ้ายและ Inspector/Missions ด้านขวาลอยทับ canvas ทั้งคู่ (ซ่อน/แสดงด้วยปุ่มลูกศรหรือ `[` `]` โดยกระดานไม่ขยับ; Fit และจุดกึ่งกลางที่วางชิ้นส่วนคิดจากส่วนที่ไม่ถูกบัง)
- ลากชิ้นส่วนจาก toolbox ด้านซ้าย (รายการเดียวแบ่งกลุ่มด้วยเส้นคั่นและชื่อหมวด; ชิปด้านบน Power / Passive / Semis / Switches / Sensors / Meters / Boards กดแล้วเลื่อนไปหมวดนั้น ชิปที่กดสว่างจนกว่าจะเลื่อนรายการเอง (ล้อเมาส์ แถบเลื่อน ปุ่มลูกศร) แล้วกลับเป็นสีเดิม; ช่องค้นหากรองจากชื่อ ชนิด หมวด และคำอธิบาย, `Esc` ล้างคำค้น)
- ต่อบน breadboard หรือลากสายอิสระบนจอเลยก็ได้ (ลากจากรูหรือขาชิ้นส่วนไปอีกจุด, กด `W` เพื่อลากสายจากจุดไหนก็ได้)
- ชิ้นส่วน: แบตเตอรี่ (1.5/3/4.5/9 V), bench supply (0–30 V + จำกัดกระแส), resistor (แถบสีอ่านค่าได้), LED 5 สี,
  diode, transistor NPN/PNP, สวิตช์ rocker, สวิตช์เลื่อน, ปุ่มกด, potentiometer, LDR, thermistor NTC, มัลติมิเตอร์ (V / A / Ω)
- ต่อผิด = ชิ้นส่วนพังจริง (ไหม้ มีควัน ต้อง Replace) พร้อมคำอธิบายเป็นตัวเลข เช่น "LED carried 1.25 A; max 30 mA"
- 9 mission แบบมือใหม่ (แท็บ Missions): เช็กลิสต์ตรวจจากการจำลองจริง + hint
- auto-save ใน browser + Export/Import ไฟล์ JSON (ไม่มีบัญชี ไม่มี server)

## คีย์ลัด

`W` โหมดลากสาย · `R` หมุน · `Del` ลบ · `F` fit · `Esc` ยกเลิก · ล้อเมาส์ซูม · `Shift`+ล้อเมาส์ปรับค่า
(pot / แสง / อุณหภูมิ / แรงดัน) · `Ctrl+Z` / `Ctrl+Y` undo / redo

สายไม่ทับชิ้นส่วน: ลากสายไปจบกลางตัวชิ้นส่วนไม่ได้ (เส้นประเป็นสีแดง), วางชิ้นส่วนทับสายแล้วสายอยู่ที่เดิม (ไม่ขยับเอง), ลากสายใหม่ระบบอ้อมชิ้นส่วนให้เอง, ลากมุม/ปลายสายไปทับชิ้นส่วนแล้วสายจะอ้อมให้เอง (ปล่อยมุมลงกลางตัวชิ้นส่วนไม่ได้; วิ่งบน breadboard ได้)

สายแตกกิ่ง: ปลายสายที่วางทับกลางสายเส้นอื่น = เชื่อมและเปลี่ยนเป็นสีเส้นหลัก มีจุดกลมตรงรอยต่อให้เห็นว่าเชื่อมกัน; ลบชิ้นส่วนที่สายลากมา สายกิ่งหายด้วย

เมาส์: ซ้าย = เลือก/ย้ายชิ้น/ลากสาย, **ลากซ้ายบนพื้นว่าง = กรอบเลือก** (ต้องคลุมทั้งชิ้น),
**ลากขวา = เลื่อนจอ** (ปุ่มกลาง หรือ `Space`+ลากซ้าย ก็ได้),
`Ctrl`+คลิกซ้าย = เพิ่ม/เอาออกจากที่เลือก (`Ctrl`+ลากซ้ายบนพื้นว่าง = เพิ่มกรอบเข้ากลุ่ม)
เลือกหลายชิ้น: `Ctrl+A` ทั้งหมด · ลากชิ้นใดชิ้นหนึ่งในกลุ่ม = ย้ายทั้งกลุ่ม · ลูกศร = ขยับทีละ 1 ช่อง grid ·
`Ctrl+C` / `Ctrl+V` คัดลอก/วาง · `Ctrl+D` ทำซ้ำ (ถ้ามี breadboard วางไว้ข้างๆ ไม่ทับ) · `Del` ลบทั้งกลุ่ม
