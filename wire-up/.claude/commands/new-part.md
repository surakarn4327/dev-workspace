ผู้ใช้ขอเพิ่มชิ้นส่วน wire-up: $ARGUMENTS

ทำตาม `PARTS.md` ทุกข้อ **ห้ามข้าม ห้ามย่อ** ทีละชิ้น (ถ้ามีหลายชิ้นให้ทำทีละตัวจนจบขั้นตอนของตัวนั้น):

1. อ่านให้ครบก่อนเขียนโค้ด: `PARTS.md`, `style.md` หัวข้อ 1.1, 1.3, 3.5, 5 (resistor), 5.14, 5.15 และโค้ดของชิ้นแบบอย่างที่สถานะ `approved` ตามตารางใน PARTS.md ข้อ 0
2. ขั้นภาพอ้างอิง: หาภาพจริงของชิ้นส่วน (เปิดใน Browser pane ได้) แล้ว **เสนอผู้ใช้**: ภาพ/ลิงก์ ขนาด ตำแหน่งขา พฤติกรรม พิกัดพัง และถามจุดที่ต้องเลือก — **หยุดรอผู้ใช้ตอบก่อนวาด**
3. ทำฟิสิกส์ + โค้ด + ไฟล์ทุกไฟล์ในตารางข้อ 3 ของ PARTS.md ใส่สถานะ `draft` ใน style.md 1.3 และ 1.2, เขียนหัวข้อ 5.x ใหม่
4. รันตรวจข้อ 5 ของ PARTS.md ทุกข้อ: `tsc`, `npm run test` (รวม `registry.test.ts`), `/gallery.html` (4 มุม pixel/vector เทียบภาพอ้างอิง + ปุ่ม Check label gaps), วางบนบอร์ดจริงแล้วลองให้พัง — ถามผู้ใช้ก่อนเปิดเบราว์เซอร์ (กฎของ workspace)
5. ส่งภาพ gallery ให้ผู้ใช้ดู แก้ตามที่ติ วนจนผู้ใช้อนุมัติ แล้วค่อยเปลี่ยน `draft` → `approved`
6. commit แยกต่อชิ้น ห้าม push จนกว่าผู้ใช้สั่ง
7. สรุปเป็นภาษาไทย: ทำอะไร ตรวจอะไรแล้ว/ยังไม่ได้ตรวจอะไร (บอกตรงๆ)
