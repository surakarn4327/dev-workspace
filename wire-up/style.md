# style.md — wire-up

**จุดกลางของหน้าตาเกมทั้งหมด** (สี ฟอนต์ ขนาด พิกเซล สไตล์อุปกรณ์)
- ก่อนแก้สี ฟอนต์ หรือหน้าตาอุปกรณ์ใดๆ ให้อ่านไฟล์นี้ก่อน
- เมื่อเปลี่ยนค่าใดๆ ในโค้ด ต้องแก้ไฟล์นี้ในงานเดียวกัน (ธรรมนูญข้อ 3 ของ `dev-workspace/CLAUDE.md`)
- ถ้าไฟล์นี้กับโค้ดไม่ตรงกัน ให้ถือโค้ดเป็นจริงแล้วแก้ไฟล์นี้ตามทันที

---

## 1. อุปกรณ์ต้นแบบ: **resistor**

สไตล์ของอุปกรณ์ **ทุกตัวต้องยึดจาก resistor** (ผู้ใช้ยืนยัน 2026-10-07 ว่าตัวอื่นยังไม่ถูกใจ)
ชิ้นส่วนอื่นที่ทำเสร็จแล้วถือเป็น "ร่าง" ไม่ใช่มาตรฐาน อย่าลอกจากมัน

### 1.1 หลักการที่ resistor ใช้ (ดูรายละเอียดใน 5)
1. **แสงมาจากมุมบนซ้าย** — ไฮไลต์ด้านบน/ซ้าย เงาด้านล่าง/ขวา
2. **ลงเงา 6–7 เฉดต่อชิ้น** — ทรงกระบอกไล่เฉดทีละแถวพิกเซล ไม่ใช่สีแบน
3. **มุมมนจริง** (`PixelGrid.rrect`/`round`) ไม่ใช่ตัดมุมบิ่น
4. **ขอบ = สีเข้มของตัวมันเอง** (resistor ใช้น้ำตาลเข้ม `#47301a`) ไม่ใช่ดำล้วนหรือนีออน
5. **จุดสะท้อนแสงเล็กๆ** ที่มุมบนซ้ายของส่วนนูน
6. **เงาตกพื้น** โปร่งแสง `rgba(0,0,0,0.38)` เยื้อง 1 พิกเซลลงขวา (ทำให้อัตโนมัติใน `PixelGrid.build`)
7. **ส่วนที่เป็นข้อมูลต้องอ่านได้จากรูป** (แถบสี resistor คำนวณจากค่าจริง)
8. **ข้อความไม่ฝังในสไปรต์** — วาดทับด้วย `drawText` (ฟอนต์ Silver)

### 1.2 สถานะอุปกรณ์ (อัปเดตทุกครั้งที่เปลี่ยน)

| อุปกรณ์ | สถานะ | หมายเหตุ |
|---|---|---|
| resistor | **pixel — ต้นแบบ** | `parts/art.ts` `resistorSprite` |
| battery | pixel (ร่าง) | ตัวมุมมน ป้ายเงิน แถบเหลืองมุมมน ยังรอผู้ใช้ตรวจ |
| multimeter | pixel (เก่า) | ใช้ขอบนีออนฟ้าและ `round()` มุมบิ่น — **ยังไม่ตรงต้นแบบ** |
| bench supply | pixel (เก่า) | เหมือน multimeter — **ยังไม่ตรงต้นแบบ** |
| LED, diode, BC547/BC557, pot, LDR, NTC, สวิตช์, ปุ่มกด | เวกเตอร์ | ยังไม่ได้ทำ |
| breadboard | เวกเตอร์ | ยังไม่ได้ทำ (ควรทำถัดไป) |
| สาย, สายอ่อนแบต/โพรบ, ควัน, แสงเรือง | เวกเตอร์ | ยังไม่ได้ทำ |

## 3. ฟอนต์และข้อความ

### 3.1 ข้อความบน canvas — `src/render/draw.ts`
- ฟอนต์: **Silver** (ฟอนต์พิกเซล, Poppy Works, CC BY 4.0, ไฟล์ `public/fonts/Silver.ttf`, โหลดใน `style.css` `@font-face` และ `main.ts`)
- สำรอง (ถ้า Silver โหลดไม่ได้): `Cascadia Mono, Consolas, Menlo, Courier New, monospace` — เหมือน agent-office
- ตัวขยาย `FONT_BOOST = 1.6` (Silver ตัวเล็กกว่า em), ไม่ใช้ตัวหนา (Silver มีน้ำหนักเดียว)
- ขนาดฐาน (`size`) = 8 หน่วยโลก, คูณด้วย `scale`
  - ป้ายค่าใต้ชิ้นส่วน: `size: 11` (เลขขา pot, ขา C/B/E: `size: 10`)
  - จอตัวเลข (supply, multimeter): `scale: 2`
- `(x, y)` ของ `drawText` = **มุมบนของกล่องข้อความ** ไม่ใช่เส้นฐาน

### 3.2 ป้ายค่าแบบมีกล่อง (`box: true`)
- พื้น**ขาว** ตัวอักษร**ดำ** `#111111` ขอบดำหนา 2 หน่วย มุมบิ่นแบบพิกเซล ระยะขอบใน 4
- แสดงเมื่อ **คลิกเลือกชิ้นส่วน** หรือ **เมาส์วางค้าง 1 วินาที** (`HOVER_LABEL_MS` ใน `ui/workspace.ts`)
- ป้ายที่ซ่อนจนกว่าจะเรียก: ค่า resistor, ค่า/เลขขา pot, ค่า LDR, อุณหภูมิ NTC, ชื่อรุ่น diode, ขา C/B/E, ป้ายแรงดันแบต
- ป้ายที่เห็นเสมอ: **ON/OFF ของสวิตช์**, ตัวเลขจอเครื่องมือ, ป้ายบนตัวเครื่อง supply/multimeter, เครื่องหมาย + ของ LED
- เหตุผล: ให้ผู้เล่นฝึกอ่านแถบสีเอง

### 3.3 ข้อความใน UI (ปุ่ม แผงข้าง) — `src/style.css`
- ฟอนต์ `'Lucida Console', Consolas, 'Courier New', monospace` ขนาด 13px (**ยังไม่ใช่ Silver** — ตัดสินใจไว้แล้วว่ายังไม่แตะ)

- ข้อความภายในเกม = อังกฤษ

## 4. ระบบพิกเซล

- **grid โลก** `G = 20` หน่วย (ระยะรู breadboard 0.1 นิ้ว) — `board/world.ts`
- **1 พิกเซลอาร์ต = `PX` = 2 หน่วยโลก** — `render/pixel.ts` (ทุกสไปรต์วางบนตารางนี้ → ตำแหน่งต้องเป็นเลขคู่)
- สไปรต์สร้างด้วย `PixelGrid` (ตารางตัวอักษร 1 ตัว = 1 สี) แล้ว `build(palette, outline, shadow)` ได้ภาพ + ขอบอัตโนมัติ + เงาตกพื้น
  - เครื่องมือ: `rect`, `rrect` (มุมมนจริง), `disc` (วงกลม), `paint(…, over)` (ทาเฉพาะทับตัวอักษรที่กำหนด — ใช้ลงเงาตามรูปทรง), `round` (ตัดมุมแบบเก่า — **เลี่ยง** ใช้ `rrect` แทน)
  - แคช `sprite(key, make)` — key ต้องรวมทุกอย่างที่ทำให้ภาพเปลี่ยน (เช่นสีแถบ)
  - `drawSprite(c, sprite, x, y)` วางช่อง (0,0) ที่พิกัดโลก (x, y) ปิด smoothing
  - ส่วนที่ขยับ (เข็ม ไฟ ปุ่ม) วาดทับด้วย `pxRect` / `pxLine` ในหน่วยพิกเซลอาร์ต
- ปุ่ม **Pixel** บนแถบบน = `scene.pixel` เปิด/ปิดสไปรต์ (ปิด = กลับไปวาดเวกเตอร์เดิม) จำค่าใน localStorage `wire-up:pixel`
- ห้ามใช้วิธีย่อภาพเวกเตอร์ลงแล้วขยาย (ลองแล้ว 2026-10-07 ภาพแตก) — ต้องวาดสไปรต์เท่านั้น

## 5. รายละเอียดต้นแบบ resistor — `src/parts/art.ts` `resistorSprite`

- ตาราง **24 × 11** พิกเซลอาร์ต (ออกมา 48 × 22 หน่วยโลก รวมขอบ 52 × 26)
- รูปร่าง: หัวสองข้างกว้าง 6 สูง 11, ตัวกลางกว้าง 12 สูง 9 (แถว 1–9), `round(2)` ที่มุม
- ลงเงาทีละแถว (บนลงล่าง):

| แถว | หัว (cap) | ตัวกลาง |
|---|---|---|
| 0 | h | — |
| 1 | L | h |
| 2 | L | L |
| 3 | T | L |
| 4 | T | T |
| 5 | M | T |
| 6 | M | M |
| 7–8 | S | S |
| 9 | D | D |
| 10 | D | — |

- จานสีตัว: h `#fff1c8` · L `#f1dba4` · T `#d9b878` · M `#c4a064` · S `#a6814a` · D `#80602f` · จุดสะท้อน `#ffffff`
- ขอบ `#47301a`, เงา `rgba(0,0,0,0.38)`
- แถบสี 4 แถบ กว้าง 2 ที่ x = 7, 10, 13, 18 (แถว 1–9): แถวบนสุด = สีผสมขาว 35%, แถว 8–9 = ผสมดำ 38%, ที่เหลือสีจริง
- จุดสะท้อนแสงที่หัว: (2,2) ขาว, (3,2) `h`, (19,2) ขาว
- วางที่ `(cx − 24, −11)` ในพิกัดชิ้น โดย `cx = ระยะห่างขา × 10`
- ขา: สองแถวหนา 2 หน่วย แถวบน `metal` `#c9ced6` (y −2..0), แถวล่าง `metalDark` `#7d838f` (y 0..2) จาก 0 ถึง `cx−26` และ `cx+26` ถึงปลาย
- ป้ายค่า: กล่องขาว ใต้ชิ้นที่ `(cx, 15)`

## 6. เช็กลิสต์เมื่อเพิ่ม/ทำอุปกรณ์ใหม่

1. เปิด 1.1 และ 5 ใช้หลักเดียวกับ resistor (แสงบนซ้าย, 6–7 เฉด, มุมมนจริง, ขอบสีเข้มของตัวเอง, จุดสะท้อน)
2. สร้างสไปรต์ใน `parts/art.ts` ด้วย `PixelGrid` และ `sprite(key, …)`; ตำแหน่งขาเป็นเลขคู่และตรงกับ `pins()`
3. ใส่ branch `if (scene.pixel) { … return }` ใน `draw()` ของชิ้นส่วน เก็บโค้ดเวกเตอร์เดิมไว้เป็นทางสำรอง
4. ข้อความ/ป้ายใช้ `drawText` (ห้ามฝังในสไปรต์), ป้ายค่าที่ซ่อนใช้ `box: true` + `scene.labeled.has(p.id)`
5. ใช้ `COL.*` ไม่ฝังสีใหม่ในโค้ด ถ้าจำเป็นต้องเพิ่มสีให้เพิ่มที่หัวข้อ 2 ของไฟล์นี้ด้วย
6. กรอบการชน (`bounds()`) ต้องคลุมรูปใหม่
7. อัปเดตตารางสถานะใน 1.2 และไฟล์นี้ให้ตรงโค้ด

## 8. ช่องว่างที่รู้ (ยังไม่ทำ / ยังไม่ตัดสินใจ)

- ชิ้นส่วนที่ยังเป็นเวกเตอร์ (ดู 1.2) และต้องปรับ multimeter/supply ให้ตรงต้นแบบ
- สาย สายอ่อนของแบต โพรบ: ยังเป็นเส้นเนียน ยังไม่เป็นพิกเซล
- แสงเรืองของ LED/LDR: ไล่เฉดเนียน ควรเป็นวงขั้นบันได (dither)
- เส้นเลือกชิ้นส่วน/วงแหวน/จุดจับสาย: ตั้งใจให้เรียบเพื่อใช้งานชัด ยังไม่ตัดสินใจว่าจะให้เป็นพิกเซลไหม
- ฟอนต์และปุ่มของ UI รอบเกมยังไม่ใช่ Silver
- เครดิตฟอนต์ Silver ยังไม่แสดงในเกม (ต้องมีก่อนเผยแพร่)
- จุด grid ไม่แสดงตอนซูมออกไกลมาก (ต่ำกว่าประมาณ 0.4 เท่า)
- อ้างอิงภาพจาก Tiny Logic: ผู้ใช้ยังไม่ได้ส่งภาพ ตอนนี้ความหนาขอบ/จานสีเดาจากหลัก pixel art ทั่วไป
