# bugs.md — agent-office

บันทึกบั๊กที่เจอและแก้จริง (ไม่ใช่ feature ใหม่) ต่อ 1 บั๊กจด 3 อย่าง:

1. **ชื่อ/อาการ** — ผู้ใช้เห็นหรือรายงานว่าอะไรผิดปกติ
2. **สาเหตุ** — root cause จริง และ pattern โค้ดที่เสี่ยงพังซ้ำ
3. **วิธีแก้** — แก้ยังไง อ้างไฟล์/บรรทัด/commit

ก่อนแก้จุดที่เคยมีปัญหา ให้ดูไฟล์นี้ก่อน

## 2026-10-02 — คูเรียร์อาจไม่ตื่นหลัง reset (หลุดจากการรีวิวโค้ด ยังไม่เคยถึงผู้ใช้)

- **อาการ**: หลังกด Reset คิวเอกสารไม่ถูกส่ง คูเรียร์นั่งเฉย
- **สาเหตุ**: loop ของคูเรียร์ `await` promise ที่เก็บ resolver ไว้ใน `this.wake` แล้วหลังตื่นสั่ง `this.wake = null` — แต่ loop ใหม่ (หลัง reset) ตั้ง `this.wake` ของตัวเองไปแล้ว loop เก่าจึงมาล้างทับ resolver ของ loop ใหม่ pattern เสี่ยง: ตัวแปร "กลไกปลุก" ร่วมกันหลายผู้รอ ที่ผู้รอล้างค่าเอง
- **วิธีแก้**: ผู้รอไม่ล้างค่าเอง ให้ผู้ปลุกเป็นคนล้าง (`kick()` ใน `src/sim/simulator.ts`) เทสต์ `jam queues several memos...` และ `reset cancels...` คุมไว้

## 2026-10-02 — Auto-answer ตอบคำถามแรกผิดหลัง Reset

- **อาการ**: กด Reset แล้วเปิด Auto-answer ชื่องานกลายเป็น "Beginners, friendly tone" แทนที่จะเป็นไอเดียงาน
- **สาเหตุ**: เลือกคำตอบสำเร็จรูปจากตัวนับ `chatSeq === 1` ซึ่งไม่ถูกรีเซ็ตตอน reset ทำให้คำถามแรกของงานถัดไปไม่ใช่ลำดับที่ 1 pattern เสี่ยง: ผูกพฤติกรรมกับตัวนับสะสมข้ามรอบ
- **วิธีแก้**: ให้แต่ละคำถามระบุคำตอบอัตโนมัติของตัวเอง (`auto` ใน `ask()` ที่ `src/sim/simulator.ts`)

## 2026-10-02 — กล่องแชทขยับขนาดตอนพิมพ์ข้อความ

- **อาการ**: กล่องสนทนา RPG สูงขึ้นทีละบรรทัดระหว่างพิมพ์ ปุ่มและช่องกรอกเลื่อนหนี
- **สาเหตุ**: เอฟเฟกต์พิมพ์ทีละตัวใส่เฉพาะส่วนที่พิมพ์แล้วลง DOM ความสูงจึงโตตามข้อความ
- **วิธีแก้**: เรนเดอร์ข้อความเต็มเสมอ ส่วนที่ยังไม่พิมพ์ใส่ใน `<span class="ghost">` (`visibility: hidden`) เพื่อกันที่ไว้ (`src/ui/dialog.ts`)
