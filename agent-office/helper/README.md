# helper — ตัวช่วยค้นเว็บ/ข่าว/อ่านหน้าเว็บในเครื่อง

เบราว์เซอร์ดึงหน้าเว็บข่าวเองไม่ได้ (ถูกบล็อก CORS) ตัวช่วยนี้เป็น Node server เล็กๆ ที่ `127.0.0.1:8071` ดึงให้แทน
**ไม่เพิ่มไลบรารี ไม่ใช้ API key ไม่ผูกบัตร** และไม่แตะ API key ของ Gemini เลย

## ใช้งาน

- `npm run dev` เปิดตัวช่วยให้เองอัตโนมัติ (ปลั๊กอิน Vite) ไม่ต้องทำอะไรเพิ่ม
- รันแยก (เช่นใช้กับแอปที่ build แล้ว หรืออยากดู log): `npm run helper`
- พอร์ตเปลี่ยนได้ด้วย `AGENT_OFFICE_HELPER_PORT`, หน้าที่อนุญาตเพิ่มได้ด้วย `AGENT_OFFICE_ORIGINS` (คั่นด้วยจุลภาค)
- ตรวจว่าทำงาน: เปิด `http://127.0.0.1:8071/health`

## เครื่องมือ (ทุกอันเป็น GET, ตอบ JSON `{ok, data}` หรือ `{ok:false, error:{code,message}}`)

| path | พารามิเตอร์ | ได้อะไร |
|---|---|---|
| `/health` | – | ชื่อ เวอร์ชันโปรโตคอล เครื่องมือ และเครื่องค้นหาที่กำลังพัก |
| `/search` | `q`, `region` (`th-th`/`us-en`/`wt-wt`), `limit` | ผลค้นเว็บ `{title,url,snippet}` จาก DuckDuckGo แล้วสำรองด้วย Bing |
| `/news` | `q`, `lang` (`th`/`en`), `days`, `limit` | ข่าวจาก Google News RSS `{title,source,published,link}` |
| `/page` | `url`, `max` (ตัวอักษร) | ข้อความอ่านง่ายของหน้าเว็บ (หัวข้อ คำอธิบาย เนื้อหา) รับลิงก์ข่าว Google ได้ (ถอดเป็นลิงก์จริงให้) |

ทุกคำขอต้องมีหัว `X-Agent-Office: 1`

## ความปลอดภัย (มีเทสต์คุมทุกข้อ)

- ฟังเฉพาะ `127.0.0.1` ตรวจ `Host` (กัน DNS rebinding) ตรวจ `Origin` (เฉพาะหน้า agent-office) และต้องมีหัว `X-Agent-Office`
- กัน SSRF: ปฏิเสธ IP ภายในทุกชนิด (รวม IPv6 ที่ซ่อน IPv4), พอร์ตแปลกๆ, user:pass ใน URL, scheme ที่ไม่ใช่ http/https
  ตรวจที่ตอน connect (ไม่ใช่แค่ตอนอ่าน URL) และตรวจซ้ำทุก redirect
- จำกัดขนาด (แตกไฟล์แล้ว) เวลา และชนิดเนื้อหา ไม่ส่งคุกกี้/Origin/Referer ไม่บันทึกคำค้นลง log

## ข้อควรรู้

- ค้นเว็บผ่านการอ่านหน้าผลค้นหา (ไม่ใช่ API ทางการ) ถ้าถูกบล็อกตัวช่วยจะพักเครื่องนั้นแล้วลองเครื่องถัดไป
  ผลค้นอาจรูปแบบเปลี่ยนได้ ถ้าพังให้ดูเทสต์ใน `search.test.ts`
- ลิงก์ข่าวของ Google ถอดเป็นลิงก์จริงด้วยช่องทางที่ Google ไม่ได้เปิดเป็นทางการ ถ้าถอดไม่ได้จะแจ้งให้ค้นด้วยชื่อข่าวแทน
- หน้าเว็บที่เนื้อหามาจาก JavaScript (ราคาที่โหลดทีหลัง) อ่านไม่เห็น เพราะตัวช่วยไม่รัน JavaScript
