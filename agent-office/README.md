# agent-office

"บริษัทเปล่า" ของ AI agent แสดงเป็นออฟฟิศพิกเซล 8-bit มองจากภายในตึก: ผู้ใช้สั่งงาน → เจ้าของเก็บ requirement → หัวหน้าแผนกแตกงาน → ลูกน้องทำ → ตรวจ → ส่งงานให้ผู้ใช้

## เริ่มใช้งาน

```bash
npm install
npm run dev -- --port 5171
```

(บน PowerShell ที่ปิดสคริปต์ ใช้ `npm.cmd` แทน `npm`)

เปิดที่ http://localhost:5171 แล้วกด **Start job** (หรือคลิก Rex เจ้าของบริษัท) กดปุ่ม **Menu** มุมขวาบนเพื่อเปิด Auto-answer, ความเร็ว และปุ่มทดลอง

- ตึกเดียว หลายห้องกั้นด้วยฉากครึ่งความสูง: ห้องผู้บริหาร ห้องประชุม ห้องไปรษณีย์ ห้อง QA แล็บวิจัย สตูดิโอผลิต ล็อบบี้ ห้องน้ำ ห้องพักเบรก ห้องเซิร์ฟเวอร์ ห้องเก็บเอกสาร ทุกห้องตัวละครเดินเข้าไปใช้จริง
- คลิกตัวละครเพื่อดูสถานะ/บทสนทนาใน Inspector
- ซูมเข้าด้วยลูกกลิ้งเมาส์หรือปุ่ม + − แล้วเลื่อนดูห้องอื่นด้วย เมาส์ชิดขอบจอ / WASD / ลูกศร / ลากเมาส์ (ปุ่ม Fit กลับไปดูทั้งตึก)
- ปุ่มทดลอง (ใน Menu): **QA reject** (รอบตรวจถัดไปตีกลับ 1 ครั้ง), **Agent error** (ลูกน้องพัง หัวหน้าเดินไปรีสตาร์ตเซิร์ฟเวอร์ที่ห้องเซิร์ฟเวอร์), **Courier jam** (กองเมโมให้คูเรียร์เคลียร์ทีละใบ)
- ตอนไม่มีงาน คนจะเดินไปชงกาแฟหรือห้องน้ำเอง และเมื่อรับงานแล้ว Sam จะเอางานไปเก็บในห้องเอกสาร

ภาษา: เมนู → LANGUAGE สลับ English / ไทย ได้ทันทีแม้ระหว่างแชท (จำค่าไว้ในเบราว์เซอร์ ค่าเริ่มต้นตามภาษาเบราว์เซอร์) ข้อความทั้งหมดอยู่ใน `src/core/strings.ts`

ทดสอบ: `npm test` (ตรรกะ core, simulator, เส้นทางผู้ใช้ และหน้าเว็บ ด้วย node + jsdom)

## สถานะ

ขั้น 1 — UI ตึกพร้อมเหตุการณ์จำลอง ใช้งานได้ครบ flow 7 ขั้น (ไม่ต้องมี key ก็เล่นเดโมได้)

ขั้น 2 — กำลังต่อ AI จริงด้วย Gemini: ใส่ API key ของตัวเอง (ชั้นฟรี ไม่ผูกบัตร) ที่เมนู → ตั้งค่า AI แล้วเจ้าของ เลขา และแผนกวิจัยจะทำงานจริง (ค้น/อ่านเว็บผ่านตัวช่วยในเครื่องที่เริ่มพร้อม `npm run dev`) แนบไฟล์ข้อความและดาวน์โหลดผลได้ที่เมนู → ไฟล์ แผนกผลิตและผู้ตรวจก็ทำงานจริง (เจ้าของเลือกแผนกตามงาน, ผู้ตรวจตีกลับได้ไม่เกิน 2 รอบ) รายละเอียดแผนและโครงโค้ดอยู่ใน `CLAUDE.md` และ `STAGE2.md`
