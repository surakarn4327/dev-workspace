# agent-office

"บริษัทเปล่า" ของ AI agent แสดงเป็นออฟฟิศพิกเซล 8-bit: ผู้ใช้สั่งงาน → เจ้าของเก็บ requirement → หัวหน้าแผนกแตกงาน → ลูกน้องทำ → ตรวจ → ส่งงานให้ผู้ใช้

## เริ่มใช้งาน

```bash
npm install
npm run dev -- --port 5171
```

เปิดที่ http://localhost:5171
