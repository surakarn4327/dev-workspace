# agent-office

"บริษัทเปล่า" ของ AI agent แสดงเป็นออฟฟิศพิกเซล 8-bit: ผู้ใช้สั่งงาน → เจ้าของเก็บ requirement → หัวหน้าแผนกแตกงาน → ลูกน้องทำ → ตรวจ → ส่งงานให้ผู้ใช้

## เริ่มใช้งาน

```bash
npm install
npm run dev -- --port 5171
```

เปิดที่ http://localhost:5171 แล้วกด **Start job** (หรือคลิก Rex เจ้าของบริษัท) ลองเปิด **Auto-answer** ถ้าอยากดูเฉยๆ

- คลิกตัวละครเพื่อดูสถานะ/บทสนทนาใน Inspector
- ปุ่ม TRY: **QA reject** (รอบตรวจถัดไปตีกลับ 1 ครั้ง), **Agent error** (ลูกน้องพัง หัวหน้าเดินมาช่วย), **Courier jam** (กองเมโมให้คูเรียร์เคลียร์ทีละใบ)

ทดสอบ: `npm test` (เทสต์ตรรกะ core และ simulator ด้วย node)

## สถานะ

ขั้น 1 — UI ออฟฟิศด้วยเหตุการณ์จำลอง (ยังไม่ต่อ AI) ใช้งานได้ครบ flow 7 ขั้น รายละเอียดแผนและโครงโค้ดอยู่ใน `CLAUDE.md`
