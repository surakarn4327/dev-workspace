# กินอะไร"ดี" (kin-arai-dee)

> อยู่ใต้ธรรมนูญ `C:\dev\CLAUDE.md` — อ่านไฟล์นั้นก่อน กฎในไฟล์นี้ชนะเมื่อขัดกัน
nชื่อที่แสดงในแอป: **กินอะไร"ดี"** (ใช้ชื่อนี้ทุกที่ที่ผู้ใช้เห็น) — `kin-arai-dee` ใช้แค่เป็นชื่อโฟลเดอร์/แพ็กเกจ

## โปรเจกต์นี้คืออะไร

เว็บแอป (เปิดบนมือถือได้) ช่วยคนดูแลผู้ป่วยตรวจว่า **เมนูอาหารที่คิดไว้ กินได้ไหม** ตามข้อจำกัดอาหารของโรค/การรักษา

- โรคแรก: **อาหารไอโอดีนต่ำ (Low Iodine Diet)** ก่อนกลืนแร่ไอโอดีนรังสี (I-131) สำหรับมะเร็งต่อมไทรอยด์
  (ผู้ใช้จริงคือหลานที่ดูแลคุณยายซึ่งกำลังจะกลืนแร่)
- ฟีเจอร์หลัก:
  1. กรอกเมนู → แตกเป็นวัตถุดิบ/เครื่องปรุง → ตรวจกับกฎของโรค → บอกผลพร้อมเหตุผล
  2. ถ้ากินได้/ปรับได้ → บอกว่าต้องใช้เครื่องปรุง **ประเภท/ยี่ห้อ** ไหน และวัตถุดิบอะไรใช้แทนได้
  3. สุ่มเมนู (จากเมนูที่ผ่านกฎแล้วเท่านั้น)
- อนาคต: รองรับหลายโรค โดยเพิ่ม "ชุดกฎ" ใหม่ ไม่ต้องแก้ logic

## คำสั่งที่ใช้จริง

```bash
npm run dev -- --port 5172      # รัน dev (พอร์ต 5172)
npm run build    # build
npm run test   # ยังไม่ได้ตั้ง
```

หรือใช้ Browser pane: `preview_start` ชื่อ `kin-arai-dee`

## โครงสร้าง

ตอนนี้ยังเป็น template Vite vanilla-ts (`src/main.ts`) — โครงที่วางแผนไว้ (อัปเดตเมื่อสร้างจริง):

- `src/data/conditions/<id>.ts` — ชุดกฎต่อโรค เช่น `low-iodine.ts` (ห้าม/จำกัด/อนุญาต + แหล่งอ้างอิง)
- `src/data/ingredients.ts` — ฐานวัตถุดิบ/เครื่องปรุง พร้อมหมวด (อาหารทะเล, นม, ไข่แดง, เกลือ ฯลฯ)
- `src/data/brands.ts` — ยี่ห้อเครื่องปรุงที่ **ตรวจสอบแล้ว** พร้อมแหล่งที่มา
- `src/data/menus.ts` — เมนู → รายการวัตถุดิบ (ใช้ทั้งตรวจและสุ่ม)
- `src/engine/` — logic ตรวจเมนูกับชุดกฎ (ไม่ผูกกับโรคใดโรคหนึ่ง)
- `src/ui/` — หน้าจอ

## กฎเฉพาะของโปรเจกต์นี้

นี่คือข้อมูลด้านสุขภาพ ความผิดพลาดมีผลต่อการรักษาจริง จึงมีกฎเข้มกว่าปกติ:

- **ไม่แน่ใจ = ไม่ผ่าน** สถานะของวัตถุดิบ/ยี่ห้อมี 4 ระดับ: ✅ กินได้ / ⚠️ จำกัด / ❌ ห้าม / ❓ ไม่แน่ใจ
  ของที่ไม่มีข้อมูลยืนยันต้องเป็น ❓ และแอปต้องแนะนำให้เลี่ยง ห้ามเดาว่ากินได้
- **ทุกกฎและทุกยี่ห้อต้องมีแหล่งอ้างอิง** (ใบคำแนะนำโรงพยาบาล, เอกสารทางการ, ฉลากสินค้า) และแอปต้องแสดงเหตุผลให้ผู้ใช้เห็น
- **ใบคำแนะนำของโรงพยาบาลผู้ป่วยชนะข้อมูลทั่วไป** ถ้าขัดกัน ให้ยึดใบของโรงพยาบาล
- ในไทย เกลือบริโภคถูกบังคับเติมไอโอดีน และน้ำปลา/ซีอิ๊ว/ซอสปรุงรสส่วนใหญ่ใช้เกลือนั้น
  ยี่ห้อเครื่องปรุงจึงต้องยืนยันจากฉลาก/ผู้ผลิตเป็นรายตัว
- **AI (ถ้าจะใช้) มีหน้าที่แค่แตกเมนูเป็นวัตถุดิบ** ห้ามให้ AI ตัดสินว่ากินได้หรือไม่ การตัดสินต้องมาจากชุดกฎในโค้ดเท่านั้น
  และใช้ได้เฉพาะบริการฟรีที่ไม่ต้องผูกบัตร (เช่น Gemini free tier) — key อยู่ใน `.env.local` เท่านั้น
- แอปต้องมีข้อความชัดเจนว่า **ไม่ใช่คำแนะนำทางการแพทย์ ให้ยึดคำสั่งแพทย์/นักโภชนาการ**
- ข้อความ UI เป็นภาษาไทย โค้ด/ตัวแปร/คอมเมนต์เป็นอังกฤษ
