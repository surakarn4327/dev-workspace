# งานค้นคว้า: รูปเมนูที่ใช้ได้ถูกลิขสิทธิ์

ตรวจเมื่อ 2026-10-05 — ข้อมูลรายเมนู (แหล่ง, สัญญาอนุญาต, ผู้ถ่าย, ลิงก์) อยู่ใน [`menu-images.csv`](menu-images.csv)

## วิธีตรวจ
1. **Wikidata** — ดึงรูปประจำ (P18) ของรายการที่ชื่อไทยตรงกับเมนู ทีเดียวทั้งหมด (SPARQL)
2. **Openverse** (api.openverse.org) — รวมรูปสัญญาอนุญาตเปิดจาก Flickr + Wikimedia Commons ฯลฯ
   ค้นด้วยชื่ออังกฤษ/คำอ่าน และชื่อไทย, กรองเฉพาะ **อนุญาตใช้เชิงพาณิชย์และดัดแปลงได้**
   (ตัด CC BY-ND ออก เพราะแอปจะครอปรูปเป็นจานกลม = ดัดแปลง) และเก็บเฉพาะรูปที่ชื่อ/แท็กตรงกับเมนู
3. **เปิดดูรูปจริงทุกรูป** (สูงสุด 4 รูปต่อเมนู) แล้วตัดสินว่าเป็นเมนูนั้นจริงไหม
   — ผลค้นอัตโนมัติผิดบ่อย เช่น "สุกี้" ได้สุกี้ยากี้ญี่ปุ่น, "แอ็บ" ได้รูปเครื่องบิน, "พล่ากุ้ง" ได้รูปคน
4. ยังไม่ได้ค้น **Unsplash / Pexels** — ต้องมี API key (ฟรี ไม่ผูกบัตร แต่ต้องสมัครบัญชี)

## ข้อสังเกต
- เมนูรามาฯ ทั้ง 3 ไม่มีรูปตรง (ลาบปลาทับทิม/ต้มซุปไก่มะเขือเทศ ได้แค่รูปใกล้เคียง, ข้าวผัดหมู ใช้รูป "ข้าวผัด" ได้)
- ภาคตะวันออกไม่มีรูปเลย, อีสาน/ใต้ ได้ราวครึ่งหรือน้อยกว่า — รูปเปิดส่วนใหญ่เป็นอาหารยอดนิยม/ภาคกลาง
- คุณภาพรูปจาก Flickr/Commons ไม่สม่ำเสมอ (มุมกล้อง แสง พื้นหลัง) — ยังไม่ใช่ระดับ "จานกลมตัดพื้นหลัง" ตามต้นแบบ
