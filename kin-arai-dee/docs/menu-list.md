# งานค้นคว้า: รายชื่อเมนูอาหารไทย (ร่างรอบ 2)

รวบรวมเมื่อ 2026-10-05 — **ร่างให้ผู้ใช้คัด ยังไม่ลง Supabase**
ข้อมูลดิบ (ชื่อ, ภาค, จำนวนแหล่ง, สถานะ, รหัสแหล่ง) อยู่ใน [`menu-candidates.csv`](menu-candidates.csv)

## ขอบเขตและเกณฑ์ (ผู้ใช้กำหนด)
- อาหารไทย **อาหารคาวเท่านั้น** แบ่ง 5 ภาค: กลาง, เหนือ, อีสาน, ใต้, ตะวันออก
- **เมนูที่ทำกินเองได้** (ตัดเมนูแบบร้าน/ซื้อสำเร็จ/สินค้าแปรรูปออก — ดูตารางท้ายไฟล์)
- ต้องพบในแหล่งรวมเมนู **อย่างน้อย 2 แหล่ง** · เป้า 200–300 เมนู
- **เนื้อสัตว์ที่เลือกได้ = 1 เมนู** (เช่น "ข้าวผัด" เลือกหมู/ไก่/กุ้ง) ผู้ใช้พิมพ์ "ข้าวผัดกุ้ง" ก็เจอ

## วิธีทำ
1. ดาวน์โหลดหน้ารวมเมนู 65 แหล่ง (ตารางด้านล่าง) เก็บเป็นข้อความดิบ
2. ร่างรายชื่อตั้งต้น ~330 รายการ รวมชื่อซ้ำข้ามภาค
3. นับด้วยโปรแกรมว่าชื่อเมนู (และชื่อเรียกอื่น) ปรากฏในกี่แหล่ง — ตัวเลขในวงเล็บ = จำนวนแหล่ง
4. ตัดชื่อเรียกอื่นที่กว้างเกินไป (เช่น "ลาบ", "ขมิ้น", "สะตอ") เพื่อไม่ให้นับเกิน
5. รอบ 2: หาแหล่งเพิ่มเจาะหมวดที่ขาด (แกงจืด, ยำ, น้ำพริก, ปลา, ขนมจีน, อีสาน, ใต้, เหนือ, ตะวันออก) แล้วนับใหม่

### ข้อจำกัด
- นับแบบหาคำ → เมนูที่เป็นส่วนหนึ่งของชื่ออื่นอาจได้แต้มเกิน
- ภาคกลางมีมากเพราะรวมอาหารตามสั่ง/ก๋วยเตี๋ยว/อาหารไทย-จีนที่กินทั่วประเทศไว้ด้วย
- ไม่ใช้ AI สรุปรายชื่อจากหน้าเว็บ เพราะตรวจพบว่าแต่งชื่อเมนูที่ไม่มีในหน้าจริง → นับจากข้อความดิบเท่านั้น
