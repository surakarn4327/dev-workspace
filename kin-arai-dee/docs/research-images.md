# งานค้นคว้า: แหล่งรูปภาพที่ใช้ได้ถูกกฎหมาย (แอปเปิดสาธารณะ)

ค้นเมื่อ 2026-10-05 — แอปจะเปิดให้คนทั่วไปใช้ จึงต้องใช้รูปที่มีสิทธิ์ใช้งานชัดเจนเท่านั้น

## เว็บร้าน (ห้ามคัดลอกรูป)

| ร้าน | ผล |
|---|---|
| Tops | ข้อกำหนดเขียนชัดว่าใช้เพื่อจุดประสงค์ส่วนบุคคลเท่านั้น ห้ามเผยแพร่ ส่งต่อ ดัดแปลง หรือทำซ้ำ — https://www.tops.co.th/th/page/terms-and-conditions |
| 7-Eleven (ALL Online) | ไม่มีข้อความอนุญาตให้ใช้รูป → ลิขสิทธิ์ตามปกติ ใช้ไม่ได้ — https://www.allonline.7eleven.co.th/service/help/terms/ |
| Big C | เว็บบล็อกการอ่านอัตโนมัติ (403) ยังไม่ได้อ่านข้อกำหนด — ถือว่าใช้ไม่ได้จนกว่าจะพบข้อความอนุญาต |
| Lotus's / Makro / CJ | ยังไม่ได้ตรวจ — ถือว่าใช้ไม่ได้จนกว่าจะพบข้อความอนุญาต |

→ ใช้เว็บร้านได้แค่ **ลิงก์ออกไปหน้าสินค้า** ("ดูที่ Tops") ห้ามดึงรูปมาเก็บ

| Open Food Facts (th.openfoodfacts.org) | **รูปสินค้ายี่ห้อ** + รูปฉลากส่วนประกอบ | รูป CC BY-SA 3.0 ใช้ในแอปสาธารณะ/เชิงพาณิชย์ได้ ต้องระบุที่มา+ลิงก์ — https://world.openfoodfacts.org/terms-of-use |
| Unsplash / Pexels | รูปอาหาร, วัตถุดิบสด | ใช้ฟรี รวมเชิงพาณิชย์ ไม่บังคับระบุที่มา (แต่จะระบุไว้) |
| Wikimedia Commons | อาหาร/วัตถุดิบไทยที่หาจากข้างบนไม่เจอ | แล้วแต่รูป ส่วนใหญ่ CC BY / CC BY-SA ต้องระบุที่มา |

### Open Food Facts — สถานะสินค้าไทย
- ค้น "น้ำปลา" เจอ 5 รายการ มีรูปทุกรายการ: เมกาเชฟ, หอยนางรม, กู๊ดไรฟ์ (ลดโซเดียม), เด็กสมบูรณ์, ทิพรส
- ค้น "ซีอิ๊ว" เจอ 2 รายการ: แม็กกี้, PB Farm
- ครอบคลุมยังน้อย แต่ **ใครก็เพิ่มสินค้า/ถ่ายรูปขึ้นได้ฟรี** (แอป Open Food Facts) — ถ่ายตอนไปซื้อของ ได้ทั้งรูปหน้าขวดและรูปฉลากส่วนประกอบ (ใช้ตรวจว่ามีไอโอดีนไหม)
- ข้อควรระวัง: ลวดลาย/เครื่องหมายการค้าบนบรรจุภัณฑ์อาจมีสิทธิ์ของบุคคลที่สาม (ตามข้อกำหนดของ OFF) — ใช้เพื่อระบุตัวสินค้าเท่านั้น
