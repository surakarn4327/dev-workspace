### ข้อสังเกตจากการดูหน้าจริง
- **ยี่ห้อเดียวกันอยู่ได้ทั้งสองกลุ่ม** ต่างกันที่สูตร/ฝา/ฉลาก เช่น เด็กสมบูรณ์ ซอสปรุงรส *ออร์แกนิค* = จำกัดไอโอดีน แต่ *ฝาเขียว* = เติมไอโอดีน
  → แอปต้องระบุถึงระดับสูตร/สีฉลาก ไม่ใช่แค่ยี่ห้อ และควรมีรูปขวดให้ดู
- **"ซีเจ" ในคู่มือคือซอสบุลโกกิของแบรนด์ CJ เกาหลี** ไม่ใช่ร้าน CJ (ร่างเดิมเข้าใจผิดได้)
- **น้ำปลา Mega chef อยู่กลุ่มจำกัดไอโอดีน** ทั้งที่ อย. บังคับน้ำปลาเติมไอโอดีน → ต้องตรวจไขว้กับฉลากปัจจุบันก่อนใช้
- กลุ่มจำกัดไอโอดีนไม่บอกว่า "ไม่มีไอโอดีนเลย" หรือ "มีน้อย" → แอปใช้คำว่า "ใช้ได้" ตามคู่มือ ไม่เขียนว่า "ไม่มีไอโอดีน"
- ข้อมูลทั้งหมดมาจาก **แหล่งเดียว** (รามาฯ) และเก่า (อ้างอิงเข้าถึง ธ.ค. 2563, ไฟล์ปี 2565) → ทุกยี่ห้อต้องมีป้าย "ยืนยันจากแหล่งเดียว" จนกว่าจะตรวจไขว้

## ก่อน vs หลังกลืนแร่ — กฎอาหารต่างกันไหม (ค้น 2026-10-05)

**สรุป: รายการกินได้/ห้ามกินเหมือนกัน ต่างกันแค่ "ต้องคุมต่ออีกกี่วัน" → ใช้ chip เดียว**

| แหล่ง | หลังกลืนแร่ |
|---|---|
| MSKCC (มะเร็งไทรอยด์) | กลับไปกินปกติได้ 24 ชม. หลังกลืนแร่ (ถ้าแพทย์ไม่สั่งอย่างอื่น) + ดื่มน้ำ ≥ 8 แก้ว/วัน 5–7 วัน + อมลูกอมเปรี้ยวเริ่ม 24 ชม. หลังกลืน ~3 วัน |
| แหล่งไทย (ไทรอยด์เป็นพิษ, เช่น hdmall/ศรีพัฒน์) | งดอาหารไอโอดีนสูงต่ออีก ~7 วัน |
| แหล่งต่างประเทศอื่น (รวมใน search) | หลากหลาย: 24 ชม. / 48 ชม. / 3 วัน / 5–7 วัน |

- ระยะเวลาต่างกันตามโรงพยาบาล → **แอปไม่แสดง/ไม่ถามเรื่องจำนวนวันเลย** (ผู้ใช้สั่ง: ผู้ป่วยรู้อยู่แล้ว)
- คำแนะนำที่ไม่ใช่รายการอาหาร (ดื่มน้ำมาก, อมเปรี้ยว) → ใส่ในหน้าข้อมูลเป็นข้อแนะนำหลังกลืนแร่ ไม่ใช่กฎตรวจเมนู
- MSKCC: https://www.mskcc.org/cancer-care/patient-education/radioactive-iodine-therapy-thyroid-outpatient-treatment
- hdmall: https://hdmall.co.th/blog/hdcare/thyroid-radioiodine-treatment-process/

### แหล่งและหลักตัดสิน
- **รามาฯ** ตารางไอโอดีนต่ำ/ปานกลาง/สูง (PDF หน้า 9–16) + หน้า 2 (ตัวอย่างอาหารไอโอดีนสูง: อาหารทะเล เกลือ เครื่องปรุง/อาหารเสริม)
- **MSKCC** Low-Iodine Diet — https://www.mskcc.org/cancer-care/patient-education/low-iodine-diet — ใช้เป็นหลักทั่วไปของหมวดที่รามาฯ ไม่มีในตาราง
- แหล่งขัดกัน → ใช้ข้อที่เข้มกว่า และเขียนใน `source` ว่า "แหล่งเห็นต่าง":
  - เนื้อหมู/ไก่/วัว: รามาฯ ปานกลาง vs MSKCC อนุญาต → **จำกัดปริมาณ**
  - เนื้อแปรรูป (แฮม เบคอน ไส้กรอก ลูกชิ้น): รามาฯ ต่ำ–ปานกลาง vs MSKCC ห้าม → **ห้าม**
  - ปลาหมึก: รามาฯ ปานกลาง vs MSKCC ห้ามอาหารทะเล → **ห้าม**
  - เต้าหู้/ถั่วเหลือง: MSKCC ห้าม, รามาฯ ไม่ระบุ → **ห้าม**
  - นม: รามาฯ ต่ำ vs MSKCC ≤ 30 มล./วัน → **จำกัดปริมาณ**
- **ข้อค้นพบสำคัญ: ไข่ไก่ทั้งฟอง = ไอโอดีนสูง (49 มคก./100 ก.)** ใช้ได้เฉพาะไข่ขาว → ของทดแทนในคอลัมน์ `substitute`
- ข้าวขาวไม่มีในตารางรามาฯ (มีแต่ข้าวเจ้าหอมนิล = ต่ำ, ข้าวซ้อมมือ = ปานกลาง) → ให้ "กินได้" ตาม MSKCC
