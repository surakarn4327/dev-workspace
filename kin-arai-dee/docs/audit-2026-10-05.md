# ตรวจความถูกต้องของข้อมูลวัตถุดิบ (2026-10-05)

ผู้ตรวจ: Claude (ไม่ใช่แพทย์หรือนักกำหนดอาหาร) — ผลนี้เป็นการเทียบแหล่งอ้างอิง **ไม่ใช่การรับรองทางการแพทย์**
ควรให้แพทย์หรือนักกำหนดอาหารทบทวนอีกชั้นก่อนเปิดให้คนทั่วไปใช้

## วิธีตรวจ

1. อ่านภาพทุกหน้าของคู่มือรามาฯ (PDF 18 หน้า) ด้วยตาเอง
   - หน้า 5-12 (เครื่องปรุง): เทียบรายชื่อยี่ห้อกับ `rama-seasonings.csv` — ยี่ห้อ/ชนิด/รุ่นที่ระบุตรงกับคู่มือ
   - หน้า 13-27 (ตารางอาหาร ต่ำ/ปานกลาง/สูง): ถอดเป็น `rama-food-table.csv` 180 รายการ
2. เทียบสถานะวัตถุดิบ 316 ชนิดใน `ingredient-iodine.csv` กับตารางนี้ด้วยสคริปต์ (`scripts/_audit.mjs`)
3. อ่านรายการวัตถุดิบของทั้ง 132 เมนูทีละเมนู เทียบกับสูตรทั่วไป และค้นสูตรจริง (Cookpad, Wongnai, Kapook) ยืนยัน 5 เมนู:
   ผัดกะเพรา, ผัดผักบุ้ง, ผัดฉ่า, ต้มยำ, ข้าวผัดหมู

## สิ่งที่แก้

| จุด | เหตุผล |
|---|---|
| งาขาว: กินได้ → จำกัดปริมาณ | รามาฯ ระบุงาดำ 21 มคก./100 ก. (ปานกลาง) ไม่มีค่างาขาว ใช้ข้อที่เข้มกว่า |
| เม็ดมะม่วงหิมพานต์: กินได้ → จำกัดปริมาณ | รามาฯ ระบุถั่วลิสง 8 (ปานกลาง) ไม่มีค่าเม็ดมะม่วงหิมพานต์ |
| บะหมี่ไข่: คำแนะนำเดิม "เปลี่ยนเป็นไข่ขาว" ผิด | แก้เป็น "เปลี่ยนเป็นเส้นที่ไม่ใส่ไข่" (ข้อมูลเดิมคัดลอกมาจากแถวไข่) |
| ปลาเก๋า ปลาอินทรี: ห้าม → ไม่แน่ใจ | เดิมระบุระดับ "สูง" โดยไม่มีค่าในตาราง ปลาทะเลบางชนิดอยู่ปานกลาง (ปลากระบอก 26, ปลาโอ 23) |
| ปลาดุก: แก้เหตุผลให้ตรงความจริง | ไม่มีค่าปลาดุกในตาราง ใช้ระดับปานกลางไว้ก่อน (ปลานิล 18) |
| เพิ่มวัตถุดิบที่สูตรจริงมักใส่ | ซีอิ๊วขาว/ซีอิ๊วดำ ใน ผัดกะเพรา และ ข้าวผัดกะเพรา; ซีอิ๊วขาว และผงปรุงรส (ไม่บังคับ) ใน ผัดผักบุ้ง; ซอสปรุงรส ใน ผัดฉ่า; น้ำพริกเผา (ไม่บังคับ) ใน ต้มยำ; ซีอิ๊วดำ ใน ข้าวผัด |
| เพิ่ม "ผงปรุงรส" เป็นวัตถุดิบต้องตรวจส่วนประกอบ | ผงปรุงรสสำเร็จรูปมักมีเกลือ (หลักการเดียวกับผงพะโล้) |

## ที่ยังไม่แน่ใจ — ต้องให้แพทย์หรือนักกำหนดอาหารตัดสิน

1. **ข้าวขาวขัดสี (ข้าวสวย ข้าวหอมมะลิ ข้าวเหนียว):** แอปให้ "ทานได้" แต่คู่มือรามาฯ ไม่ระบุค่าข้าวขาว
   ระบุเฉพาะข้าวซ้อมมือ (ข้าวหอมมะลิซ้อมมือ 16, ข้าวเหนียวซ้อมมือ 12 มคก./100 ก. = ปานกลาง) ข้าวเป็นอาหารหลักที่ทานปริมาณมาก
   ถ้าเป็นข้าวซ้อมมือ ค่าอาจเกือบถึงเพดาน 50 มคก./วัน ในมื้อเดียว
2. **วัตถุดิบ 117 ชนิดที่สถานะ "กินได้" ได้จากการอนุมานตามหมวด** (ผัก สมุนไพร เส้น แป้ง เครื่องเทศ) ไม่มีชื่อตรงในตารางรามาฯ
   โดยเฉพาะ: สะตอ ชะอม ลูกเกด หน่อไม้ เห็ดฟาง เห็ดหูหนู เลือดหรือดีวัว เส้นก๋วยเตี๋ยว/วุ้นเส้น (เส้นสำเร็จรูปอาจมีเกลือ)
3. **เมนูไข่:** ใช้หลัก "ใช้เฉพาะไข่ขาวได้ถือว่าผ่าน" ตามที่ผู้ใช้ตัดสิน ผู้ป่วยต้องเข้าใจว่าต้องทิ้งไข่แดง
4. **น้ำซุป (กระดูกหมู ไก่ เป็ด เนื้อ):** ทำเองไม่มีปัญหา แต่ซุปก้อนและน้ำซุปสำเร็จรูปอาจมีเกลือเสริมไอโอดีน
5. **ยี่ห้อแหล่งเดียว:** ยี่ห้อส่วนใหญ่ยืนยันจากคู่มือรามาฯ แหล่งเดียว (คู่มืออ้างอิง ธ.ค. 2563 สูตรอาจเปลี่ยน)
6. **คู่มืออ้างอิงตัวเลขกรมอนามัย (2561)** ซึ่งผมไม่ได้เทียบกับต้นฉบับ

## ที่ผมไม่ได้ทำ

- ไม่ได้ค้นสูตรจริงครบทุกเมนู (ค้น 5 เมนู ที่เหลืออ่านเทียบความรู้ทั่วไป) ควรทำต่อรอบละ 10-20 เมนู
- ไม่ได้เทียบกับตาราง MSKCC ต้นฉบับ (ใช้ข้อมูลที่บันทึกไว้ในงานค้นคว้าเดิม)
- ไม่ได้ตรวจว่าไอโอดีนของอาหารแปรรูปแต่ละยี่ห้อ (นอกจากรายการรามาฯ)

# รอบตรวจสูตรเทียบแหล่งจริง (2026-10-06)

วิธี: เปิดหน้าสูตรจริงอ่านรายการวัตถุดิบ เทียบกับ `menu-ingredients.csv` เพิ่มเฉพาะวัตถุดิบที่พบใน **อย่างน้อย 2 หน้าสูตรที่เปิดอ่านจริง**
เลือกตรวจเมนูที่แอปตอบ ✅ ได้ก่อน (60 เมนู) เพราะถ้าตกวัตถุดิบเสี่ยงเมนูกลุ่มนี้จะให้คำตอบผิดได้มากที่สุด
เมนูที่แอปตอบ ❓/❌ อยู่แล้ว (เช่น เมนูที่ใช้พริกแกงสำเร็จรูป กะปิ ปลาร้า) เพิ่มวัตถุดิบเข้าไปก็ไม่เปลี่ยนผล จึงยังไม่ได้ตรวจในรอบนี้

**ผลการตรวจ:** เพิ่มวัตถุดิบ 28 แถว ไม่มีเมนูใดเปลี่ยนผลตรวจ (เทียบผลทุกเมนูทุกตัวเลือกเนื้อสัตว์ก่อน/หลังแล้ว) เพราะที่เพิ่มเป็นเครื่องปรุงที่ต้องเลือกยี่ห้อ หรือวัตถุดิบไม่บังคับ
ไม่พบกะปิ กุ้งแห้ง ปลาร้า ที่ตกหล่นในเมนูกลุ่ม ✅ — ข้อมูลเดิมครอบคลุมแล้ว

## ยังไม่ได้ตรวจในรอบนี้

เมนูที่ตอบ ❓/❌ อยู่แล้ว 72 เมนู (แกงทุกชนิด เมนูที่ใช้กะปิ ปลาร้า น้ำพริกเผา ฯลฯ) — เพิ่มวัตถุดิบเข้าไปไม่เปลี่ยนผล แต่รายการที่แสดงอาจยังไม่ครบ
และเมนู ✅ ที่ไม่ได้เปิดอ่านหน้าสูตรของตัวเอง: ข้าวไข่เจียว ไข่ดาว ไข่ป่าม ข้าวกั๊นจิ๊น จิ้นส้ม ก้อย ต้มแซ่บ หลนเต้าเจี้ยว น้ำพริกหนุ่ม น้ำพริกเผา เนื้อแดดเดียว หมูย่าง ปีกไก่ทอด ซุปหางวัว ข้าวต้มกุ๊ย ยำปลาดุกฟู
(เมนูกลุ่มนี้อ่านจากผลค้นหารวมเท่านั้น ไม่ได้เปิดหน้าสูตรเต็ม)
