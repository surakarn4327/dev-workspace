## โปรเจกต์นี้คืออะไร

คุมเปิด-ปิดคอมจากมือถือผ่าน ESP32+relay พร้อมเช็คสถานะและแจ้งเตือน

## คำสั่งที่ใช้จริง

```bash
npm run dev -- --port 5170      # รัน dev (พอร์ต 5170)
npm run build    # build
npm run test   # ยังไม่ได้ตั้ง     # test
```

หรือใช้ Browser pane: `preview_start` ชื่อ `pc-controller`
