# game-dev-simulator

Roblox tycoon — เด็กธรรมดาผันตัวเป็น game dev ไต่จากศูนย์: สร้างเกม → ตระเวนขายตามคุณภาพ →
ปั้นทุนซื้อบริษัทเล็ก → จ้างพนักงาน → แข่งขันกับสตูดิโออื่น

## เริ่มใช้งาน

1. ติดตั้ง [Aftman](https://github.com/LPGhatguy/aftman) แล้วรัน `aftman install` (ติดตั้ง Rojo ตามเวอร์ชันที่ pin ไว้)
2. เปิด Roblox Studio ติดตั้ง [Rojo plugin](https://rojo.space/docs/v7/getting-started/installation/#installing-the-roblox-studio-plugin)
3. รัน:

```bash
rojo serve
```

4. ใน Roblox Studio กด Connect ใน Rojo plugin — โค้ดจาก `src/` จะ sync เข้า Studio แบบ live
